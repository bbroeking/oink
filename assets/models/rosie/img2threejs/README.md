# Rosie img2threejs Prototype

This folder is an isolated experiment using the `hoainho/img2threejs` workflow against
`assets/concepts/rosie-3d/v3-rig-ready/rosie-rig-ready-left-v3.png`.

What it creates:

- `rosie-pre-spec-assessment.json` from the img2threejs stage 2 scaffold.
- `rosie-detail-inventory.json` and `detail-inventory/` crops from the stage 1 detail scanner.
- `rosie-anatomy-landmarks.json` and `rosie-landmarks-overlay.png` from the character landmark helper.
- `rosie-object-sculpt-spec.starter.json`, the stock starter spec generated by the tool.
- `createRosieImg2ThreejsModel.js`, a hand-authored procedural Three.js factory following the img2threejs action-ready component idea.
- `rosie-img2threejs-preview.html`, a standalone browser preview with a simple walk loop.

Current verdict: this route is promising for Rosie as a game asset because the body, legs,
and tail are separate `Object3D` pivots. It is not a rigged GLB and it is not photogrammetry.
It is a procedural Three.js character that can animate cleanly without a skinning solve.
