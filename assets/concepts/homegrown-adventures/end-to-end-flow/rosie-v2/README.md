# Rosie-native correction set

This second ImageGen pass corrects the character and world-style drift in the first flow.

## Character lock

- Rosie remains a four-legged chibi pig in every state.
- Compact round head/body silhouette; four short legs and dark hooves.
- Two upright pointed ears, huge dark oval eyes, small pink oval snout, round blush cheeks, and a tiny curled tail.
- Thin dark-plum outlines and soft cel-painted shading match the canonical Rosie references.
- Bags and props attach to her quadruped body; she never stands like a person or uses human hands.

## World-style correction

- Larger rounded shapes and gentler pastel gradients.
- Less gritty brush texture, micro-flower noise, realistic lighting, and heavy detail.
- The environment and UI use the same delicate outline, softness, and visual simplicity as Rosie.
- The fixed camera, Barn geography, three beds, causal loop, and one-action hierarchy remain unchanged.
