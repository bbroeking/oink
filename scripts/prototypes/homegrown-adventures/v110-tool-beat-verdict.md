# v0.110 Tool beat prototype verdict

## Question

Can the Tool cause read from Rosie's response and the physical expedition instead of a large field-note receipt?

## Compared

- **A — Field note:** the current Tool receipt across the top of the clearing.
- **B — Trail label:** a smaller ground-level label beside the physical Tool.
- **C — Ground answers:** no local card; Rosie notices, the Tool acts, route-colored ground details rise, and the existing HUD names the exact cause.

## Verdict

**C — Ground answers wins.**

A covers the route and makes the action feel reported. B preserves more of the scene but remains another card and competes with the Tool itself. C keeps Rosie, the Hand Trowel or Lantern, the waking Glowroot or reflected leaves, and the clearing in one visual sentence. Its HUD remains exact on both complete and Near-Discovery branches.

The production checkpoint should therefore:

1. remove the visible field note from the Tool beat only;
2. keep the existing authored `Rosie Notice` response and physical Tool action;
3. name Hand Trowel, Lantern, and no-Tool outcomes in the existing HUD for both routes;
4. add only a restrained route-colored ground response, with hidden live-region cause text; and
5. preserve the current 900 ms beat, reduced-motion behavior, reducer outcomes, Rive binary, and later Pack receipt.

This remains one presentation correction. It adds no encounter, reward, destination, inventory rule, timer, save fact, or screen.
