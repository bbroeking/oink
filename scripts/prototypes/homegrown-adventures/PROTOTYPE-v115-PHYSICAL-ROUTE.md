# v0.115 physical-route prototype

Question: can Position 9 preserve its exact **Set off → named route →
Homeward / Home** contract without laying a numbered progress widget across
the Barn roof?

Run `npm run prototype:homegrown`, then open Position 9 with `?path=A`,
`?path=B`, or `?path=C`. The floating switcher and Left/Right arrow keys cycle
the same variants.

- **A — Path stones:** three labeled stones follow the painted path.
- **B — Tied waymarks:** three colored tags act as physical trail markers.
- **C — Living lights:** the existing route-colored lights become the visual
  route, while the exact ordered list remains available to assistive
  technology and one current phrase names the visible state.

Verdict: **C wins.** It reuses an established world object, leaves the Barn and
path unobstructed, and makes route color and direction part of the landscape.
A still reads like board-game pieces laid over the illustration. B invents a
new prop language and competes with the Farm. Main should retain only the
living-light treatment, without the switcher or losing structures.
