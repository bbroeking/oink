# v0.111 Pack beat prototype verdict

## Question

Can the final Bag cause resolve through the physical find-to-Pack handoff instead of the last large field-note receipt?

## Compared

- **A — Field note:** the current large Pack receipt above Rosie.
- **B — Pack label:** a smaller label beside the selected Pack.
- **C — Pack answers:** no local card; the find moves into the Pack, the Pack answers with one restrained finish, and the existing HUD names the exact cause.

## Verdict

**C — Pack answers wins.**

A makes the player read while the find is moving. B preserves more of the clearing but still competes with the transfer it describes. C completes one visual sentence: Rosie finds something, the selected Pack receives or protects it, and the HUD explains why that outcome happened. Empty Pack remains a kind Near-Discovery and must never show a find being collected.

The production checkpoint should therefore:

1. remove the visible field note from the Pack beat;
2. preserve the existing complete-branch find-to-Pack handoff;
3. add one restrained Wicker, Cloth, or empty-Pack finish without adding Rive motion;
4. name complete, clue, alternative-Pack, and no-Pack outcomes in the existing HUD;
5. keep the exact cause in hidden live-region text; and
6. preserve the current 900 ms beat, reduced-motion behavior, deterministic rewards, and subsequent journey handoff.

This finishes the presentation cleanup of the existing three Bag causes. It adds no reward, encounter, destination, inventory rule, timer, save fact, Rive binary, or screen.
