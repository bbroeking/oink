## App Privacy

Data collection: **Yes**. Tracking: **No** for the verified present service
state. All selected types below are **linked to the user**, because the app
uses account IDs and associated records. Rewarded ads are globally disabled;
reassess these answers before activating them. Advertising and tracking are
separate questions from collecting data to operate the game.

| Select data type | Purpose | Actual app/SDK flow |
| --- | --- | --- |
| Email Address | App Functionality | Supabase account authentication, including Apple relay email where supplied. |
| User ID | App Functionality, Analytics | Account UUID and handle; linked gameplay analytics, Sentry scope, and RevenueCat account. |
| Device ID | App Functionality | Opted-in Expo push token; RevenueCat iOS 5.70.0 automatically includes IDFV in service requests. Conservatively disclose the latter; header retention was not verified. |
| Contacts | App Functionality | Persisted in-app friendships and Sounder membership form a social graph. The app does not read the device address book. |
| Emails or Text Messages | App Functionality | Private preset Sounder notes: saved sender, recipients, body, and timestamps. No free-form composition. |
| Gameplay Content | App Functionality | Saved progress, balances, cosmetics, achievements, Barn arrangements, social gameplay state, and Drum receipts. |
| Purchase History | App Functionality, Analytics | RevenueCat store receipt/transaction, subscription, and entitlement processing. |
| Product Interaction | App Functionality, Analytics | First-party feature-use events and Sentry release-health sessions/performance context. |
| Crash Data | App Functionality | Sentry native/JavaScript crashes and exceptions when captured. |
| Performance Data | App Functionality | Sentry sampled performance timings; tracing is configured at 10%. |
| Other Diagnostic Data | App Functionality | Error/log messages, technical breadcrumbs, and app/device/OS/release context. |
| Other Data Types | App Functionality | RevenueCat's automatic ATT authorization-status sync during lifecycle and transaction operations. This category is the conservative proposed mapping for permission-status metadata. |

**Name: leave unchecked for this iOS binary.** Frozen native Apple sign-in
requests full name but never reads or forwards `credential.fullName`; it sends
only the identity token to Supabase. Supabase explicitly documents that Apple's
identity token has no full-name claims and saving the separate name requires
an additional `updateUser` call. Build 196 makes no such call; the iOS email
sign-up path sends only email/password, and no reachable runtime name field
was found. The database trigger can copy an already-supplied provider name,
but that capability does not show collection by this iOS binary. A handle
belongs in User ID. [Supabase's Apple sign-in contract](https://supabase.com/docs/guides/auth/social-login/auth-apple).

The draft describes the confirmed username flow and does not assert unverified
provider-name/avatar collection. The earlier production aggregate was an
unnecessary prerequisite for this binary's Name selection. Its CLI attempt
stopped before execution because no access token was available; no production
values were returned. The prepared query remains as optional inventory work
for historical/shared-backend retention, which was not established either
present or absent. No Supabase sign-in is needed to close the current iOS
disclosure decision.

Do not add Other User Content solely for hypothetical free-form reports or
Sounder names: build 196 offers fixed report reasons and server-generated
Sounder names. Structured Barn arrangements fit Gameplay Content. Do not add
location, photos, audio, payment-card information, or advertising data from
unused SDK capability. The app's privacy draft describes the current flows at
[`privacy-policy-1.3.html`](../../artifacts/release-1.3/privacy-policy-1.3.html).

Apple's taxonomy specifically covers social graphs and private non-SMS
messages; username/handle, saved gameplay, diagnostics, and permission metadata
are mapped according to their actual use. [Apple App Privacy Details](https://developer.apple.com/app-store/app-privacy-details/).
RevenueCat's purchase disclosure requires App Functionality and Analytics,
with linkage when a custom account identifier is used. [RevenueCat guidance](https://www.revenuecat.com/docs/platform-resources/apple-platform-resources/apple-app-privacy).

## Age rating

| Question | Proposed answer | Candidate rationale |
| --- | --- | --- |
| Parental Controls | No | No in-app parental management tools. |
| Age Assurance | No | The dormant ad eligibility self-attestation is not an active age-assurance flow; no Declared Age Range API. |
| Unrestricted Web Access | No | No freely navigable in-app web browser. |
| User-Generated Content | Yes | Public user-authored handles in rankings/profiles; persisted player Barn layouts visible to friends. Conservative treatment of the app's shared player-created content. |
| Social Media | No | No feed that amplifies user-authored posts through comments, shares, or equivalent discovery. Profiles, rankings, and accepted-friend Barn visits are the relevant limited surfaces. The live question was inspected and uses this feed/amplification definition. |
| Social Media Disabled for Users Under 13 | No | No Declared Age Range API or under-13 social restriction. The live wizard required a separate answer even with Social Media set to No. |
| Messaging and Chat | Yes | Private member-to-member preset Sounder notes directly communicate with recipients. |
| Advertising | No in the current service | Paid advertising is globally disabled; the backend gate prevents any account's ad request. Reassess before activation. |
| Contests | Frequent | The main Friends Board offers persistent global/friends/pair rankings, updates with normal play, and surfaces overtakes. This is independent of Monday Drum. |
| Simulated Gambling | None / No | No accessible wager in build 196; the Mote Machine entry points and direct routes are compile-time hidden in production. |
| Gambling | No | No real-money stake or currency exchangeable for real money. |
| Loot Boxes | No | Random Drum rewards and Mystery Hat Boxes are earned free; premium pass rewards are fixed cosmetics. No purchasable randomized item was found. |
