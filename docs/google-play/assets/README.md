# Google Play graphic assets

- `play-icon-512.png` — 512×512, 32-bit RGBA PNG
- `feature-graphic-1024x500.png` — 1024×500, 24-bit RGB PNG
- Phone screenshots — use the six 1284×2778 PNGs in
  `docs/screenshots/v1/` after confirming each still matches the Android build

Google Play requires at least two phone screenshots. Prefer this order for the
current set:

1. `barn-default.png`
2. `season-bounty.png`
3. `shop-featured.png`
4. `leaderboard-friends.png`
5. `achievement-unlock.png`

Do not upload stale iOS screenshots blindly. Capture replacements from the Play
test-track build if Android typography, status bars, navigation, or content
differs materially.
