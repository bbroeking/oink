# Card-layout generation prompts

These prompts generate **complete card-face design concepts**, not isolated
illustrations. Use them to discover the frame, boxes, silhouette, materials, and
visual rhythm. Final names, rules, numbers, icons, and QR codes should be added
as clean vector artwork afterward.

For Midjourney, place a Rosie reference-image URL before the prompt when
generating a Rosie card. Use a portrait `5:7` aspect ratio. Generate layouts
straight-on rather than as photographed tabletop mockups.

## Shared negative direction

Append this to every prompt:

> front-facing flat card design, perfectly centered, complete card visible,
> print-design presentation, no perspective, no hands, no tabletop, no booster
> pack, no readable words, no fake letters, no lorem ipsum, no QR code, no
> watermark, no brand logos, no maple leaves, no copied trading-card frame,
> no sleek mobile-game UI, no generic rounded rectangles, no minimalist beige
> dashboard, no photorealism

Suggested Midjourney suffix:

`--ar 5:7 --stylize 350 --chaos 8`
