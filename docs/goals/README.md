The Mote draft assumes earned-currency wagering with losses alongside the
existing guaranteed Reveal. Its stakes and paytable are proposed defaults;
the spec records the audience-rating decision needed for rollout. Housing
keeps the six-position Barn concept and provides deterministic furnishing
sources, with proposed starter/catalog changes called out explicitly.

Both goals prefer Sol, Terra or Luna sub-agents and include bounded work
packages, tests, production asset requirements and completion evidence. The
lead owns integration. Root `AGENTS.md` records this model preference for
future project work.

Either project can go first. If both chats run concurrently, give them isolated
worktrees and coordinate shared types, navigation, source assets, release
follow-ups and migration timestamps at integration. Neither chat should
overwrite the other's changes or apply the other's pending migrations.
The optional shared connection is a Barn cabinet opening the existing machine
and inventory; random furniture rewards are deferred in both V1 specs.
