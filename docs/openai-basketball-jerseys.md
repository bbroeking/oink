# OpenAI / ChatGPT Basketball Jersey Mockups

Concept pass: what basketball jersey cosmetics would look like in TTP.
Batch 1 puts them ON Rosie (concept mockup); Batch 2 renders jersey-only
flat cutouts in the standard accessory-pipeline style so a winning design
is near-production-ready.

## Workflow

1. Drag refs into ChatGPT: `idle_1.png` (Rosie idle pose — the style anchor).
2. Paste the style anchor below, wait for acknowledgment.
3. Send Batch 1, then Batch 2. Download each result.

## Style anchor (paste once)

```
I'm going to ask you to generate concept images of basketball jersey
cosmetics for a 2D mobile game starring the pig in the attached
reference image (her name is Rosie). Match the reference's art style
EXACTLY:
- Flat children's storybook illustration with bold ~3px black outline
- Soft saturated colors, clean palette
- Simple shapes, very readable at small sizes (this is a mobile game)
- No drop shadows, no glow, no 3D shading, no gradients
- Pure transparent background

Some batches will show Rosie WEARING items (concept mockups); others
will be item-only sprite strips with NO character. Each batch states
which. Confirm you understand, then I'll send the first batch.
```

---

## Batch 1 of 2 — Rosie wearing the jerseys (concept mockup, 2×2)

```
BATCH 1: a 2×2 grid, four cells, each showing the SAME pig from the
reference (Rosie, identical pose and proportions, front-facing idle)
wearing a different sleeveless basketball jersey. The jersey drapes
over her torso only — legs, head, ears, arms stay exactly like the
reference. Flat 2D front view, storybook style per the anchor.
1. Top-left: "MUD HOGS" — chocolate-brown jersey, gold trim, gold
   block number 67 on the chest, small hoof-print logo
2. Top-right: "HILLTOPPERS" — sky-blue jersey, white trim, white
   number 12, small mountain-peak logo
3. Bottom-left: "VALLEYFOLK" — meadow-green jersey, cream trim,
   cream number 8, small daisy logo
4. Bottom-right: "TROTTERS" — classic cream jersey with rose-pink
   pinstripes, pink number 25, retro arched lettering
No labels outside the cells, no gridlines, transparent background.
```

## Batch 2 of 2 — Jersey-only flat cutouts (production style, 4-cell strip)

```
BATCH 2: NO pig, NO character — items only. A 4-cell horizontal strip
of the SAME four jerseys from Batch 1, each as a sleeveless basketball
jersey laid flat, front view only.
RENDERING RULES (CRITICAL):
- Each item is a PURE 2D PAPER CUTOUT viewed straight from the front.
- NO back-of-collar, NO underside, NO inner cavity — the neckline and
  armholes are SOLID PAINTED EDGES, never openings showing an inside.
- Think: a sticker glued to a flat surface — not a 3D-rendered object.
- Flat colors, bold ~3px black outline, no shading.
Order: 1. Mud Hogs (brown/gold #67)  2. Hilltoppers (sky/white #12)
3. Valleyfolk (green/cream #8)  4. Trotters (cream/pink pinstripe #25)
Centered per cell, consistent margins, no labels, no gridlines,
transparent background.
```
