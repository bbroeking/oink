Rules
One palette. A new color is a token, never a fresh hex. 54 distinct raw hex values still leak in 22 files; each is a token to add or a token to use.
Rust is a kicker, never a fill. The accent appears above titles and on links; the moment it is a button it stops being the accent.
Bark is the only dark. No #1A1A1A wrappers, no black flashes. Dark buttons use ink.
Alignment tints stay on alignment surfaces. angel / goblin / bless / curseGreen never decorate unrelated cards.
Retire COLORS. The legacy ramp (ink2–4, paper2–3, pink, purple) folds into WHIMSY / UI_COLORS; 14 call sites remain.
Contrast fixes at the root. muteSoft fails AA on all 14 surfaces yet is named textDisabled — a text-safe muteDim takes the role and muteSoft becomes uiMuted (never text). textPlaceholder and focus roles are added. RARITY_BADGE {bg, ink} replaces the third rarity map in hats.ts (fails AA at every rarity today).

OPACITY replaces the 0.45–0.9 ladder (70× 0.7, 28× 0.85, 22× 0.6 …) and the five different "pressed" values inside the primitives. Text colour never comes from opacity. Disabled controls never use it.
PRESSED / DISABLED style tokens: pressed = translate by the shadow offset and collapse the shadow (the Barn tray's press); disabled = cream2 fill · ink outline · muteDim text · no opacity. Nine pressed idioms and five dissolves exist today.
TINT names the 41 rgba( literals, all derived from ink via inkAlpha(a): scrim .55 (corrects UI_COLORS.scrim, which uses rgba(40,30,20) where ink is #2a1f15) · inkWash .08 · well .12 · paperWash · sunGlow.
MOTION: tap 120 · fade 180 · sheetIn 300 / sheetOut 180 · modalHandoff 320 · toast 2400. MOTION_SPRING: tap {14, 220} · settle {12, 180} · sway {6, 60} · overshoot {8, 140} — one parameterization for the 20 springs / 14 configs shipping today. Reduce Motion: every decorative loop has a rest pose; a file that imports Animated imports useMotionPolicy.
