# Big Twelve — Family Review

Owned private Claude Design page: `Big Twelve - Family Review.dc.html` in the existing Tickle the Pig Card Packs project. Claude Design normalizes the em dash in page names to a hyphen.

This pass waits for the completed Base Pigs, Actions, Items, and Locations exports, then reuses those actual faces. The optional new-pig concepts are included only if ready and clearly provisional.

## Comparison plan

- A straight-on comparison sheet uses exact 320 × 448 faces on a neutral surface. Preserve each family’s composition and approved content.
- A static three-card draft shows the existing Action, Item, and Location faces together. No invented reward behavior, deck size, co-op scope, or numerical facts.
- A compact deck browser uses readable name/type/cost rows and a full-size card inspection. Miniature faces are recognition aids; complete rules remain readable in the 320px inspection.
- Long-name and long-rules checks use actual completed content. If a synthetic stress fixture is needed, it remains explicitly labeled outside gameplay as a typography test.
- Inspect full-size and 390px presentation in one batch. Correct concrete readability and consistency issues once on this review page only, then confirm once.
- Report source-family defects; never edit another pass’s page, output, or shared design-system files.

## Checks

Type and name recognition, applicable cost/stat distinction, complete rules at ≥15px Nunito with comfortable line spacing, continuous cocoa perimeter, equal outer dimensions, uniform original-art scaling, protected text, safe overlaps, contrast, and structural distinctions beyond color.

Scope is a static private design review. Production app, gameplay, tokens, API, database, release artifacts, and implementation remain outside this pass.
