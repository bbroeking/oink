# Big Twelve — Family Review

Completed private Prompt 6 review page in [Claude Design](https://claude.ai/design/p/aec2145f-9fe2-4416-ab82-50c0100f537d?file=Big+Twelve+-+Family+Review.dc.html), using the selected Tickle the Pig Design System. Final verification: October 14, 2026. The project normalizes the canvas filename to an ASCII hyphen; the page heading retains the em dash.

The review contains a full-size Pig/Action/Item-source comparison, a static three-Action draft sample, compact deck-browser rows with a 320px Duck Into the Mud inspection, actual long-name/rules evidence, and the three provisional pig concepts. All source families are read-only. No replacement Location or missing Item art was invented.

## Findings

- **Pigs and Actions pass this static composition review.** Their type reading order differs structurally: Pig art/large Cheer/name below/diagonal pasture; Action title/compact Energy/art band/effect below. Exact complete prototype catalog rules remain readable, including Pickles and Duck Into the Mud. Energy and adventure adaptation remain TBD.
- **Items remain incomplete.** All three original object artworks are absent from the delivered source, and its effects/rules remain TBD. The object layout can be compared, but artwork recognition, perceived scale and completed rule capacity cannot be accepted. The source's older crest Action and co-op Rosie comparisons were excluded.
- **Locations remain unavailable.** Its dependency ended with a blank Claude page after project-level generation/chat-isolation blockers. No Location export was delivered, so its composition, crop, text and type distinction cannot be evaluated.
- **Mixed-family draft acceptance is pending.** The three-card draft sample uses only completed Actions and labels that limitation. The browser shows incomplete Item rows and an unavailable Location row, with Rosie separately identified as the leader.
- **New pigs remain provisional.** Mallow, Pip and Dozer reuse their actual completed concept faces, with proposed hooks and TBD numerics. Their earlier E geometry differs from the refined Base Pigs and is explicitly disclosed.

## One focused correction batch

The first export reproduced all 12 faces exactly from the frozen source markup. Independent inspection found that the incomplete Item `image-slot` exposed Replace/Edit/browse/drop controls in an otherwise static review. Claude replaced only that review instance with a fixed 214×146 cocoa/Nunito “Original artwork missing” placeholder, removed its editing script, and updated the caption. No artwork was substituted. Three compact Action rows were aligned to “TBD Energy” to match the faces.

The final export preserves all **11 completed Pig/Action/concept faces exactly** after whitespace normalization. The sole face difference is the deliberately frozen incomplete Item placeholder. Source hashes confirm that the four dependency HTML files remain unchanged. No shared component, design-system file, original art, production code, gameplay, API, database, release artifact, or SKILL.md was changed by this pass.

## Verification

Two independent assessments preceded the correction, followed by one lead confirmation batch. At desktop 1280px, 390px and 320px widths, all 12 printed faces measure exactly **320×448**, stay within the viewport, and retain contained text. The document width equals the viewport width in all three cases. Rules stay **15px Nunito / 22.5px line height**. All expected images and Caprasimo/Nunito/Patrick Hand fonts load. Sample contrast measurements range from 5.72:1 to 15.46:1. The final page has zero editable controls and no animation, transform, depth or tilt.

The detector's 27 findings were authored-card false positives: 12 cramped-padding, 6 design-system-font, 1 design-system-radius, 7 design-system-font-size and 1 cream-palette. Computed 21px text insets, fixed card geometry, intended loaded fonts and visible contrast resolved those signals. No detector overlay was injected: the browser evaluation surface is read-only; computed DOM and screenshots supplied the evidence. Review is static artifact verification, not gameplay or native-device acceptance.
