# Member expansion & QoL backlog

Ideas captured 2026-07-10 for deepening the game **for Slop Club members without
breaking the core loop.** Nothing here is committed except the Companion Critter
(in progress — see `docs/companion-critter-spec.md`).

## The governing principle

Member add-ons run **parallel** to the core loop, never **multiply** it. The
competitive engines — The Board (ranks by lifetime **tickles**) and the dig-off
(ranks by **finds**) — stay identical for everyone. Members get *more game around*
those engines (build, express, socialize, explore), never a faster/stronger
version of them. Anything that prints tickles or finds is pay-to-win and off the
table. Basic usability stays **free**; only "extra"/identity/expansion content is
gated.

## Member expansions (parallel loops)

- **The Den — decorate Rosie's home.** A furnishable room/barn interior: place &
  arrange furniture, plants, decor from pass/shop/digs. A bottomless collect-and-
  arrange loop, zero loop impact. Best *subscription* stickiness (ongoing, not
  one-and-done). *Flagship candidate. Big build.*
- **Rosie Studio (photo mode).** Pose Rosie, pick scene/backdrop, add props/
  frames, snap & share a postcard. Members get more props/backdrops. Doubles as
  marketing (ties to the covers pipeline). *Medium.*
- **Companion Critter.** A small follower (duckling / bee / firefly) that roams
  the home screen; cosmetic-only, never earns tickles/finds. **← NEXT, in
  progress.** *Medium.*
- **Barn visiting + guestbook.** Visit friends' barns/dens, leave a stamp/gift,
  sign a guestbook. Deepens Connect; makes decorating/dressing *seen*. Already
  half-designed (`docs/barn-visiting-design.md`). *Medium.*
- **Recolor / dye bench.** Members recolor owned cosmetics — multiplies
  expression from the existing catalog with little new art. *Small–medium.*
- **Member story + Museum/Almanac.** Extra lore chapters + a catalog of every
  cosmetic (with completion + a home for exclusive titles to be admired). *Medium.*

## QoL (tag: FREE base vs PREMIUM treat)

- **Saved Looks (outfit presets)** — save/name/one-tap-equip full outfits.
  *Feature free (~2 slots); PREMIUM grants extra slots. Medium.*
- **Rename Tokens** — consumable to rename Sounder/self (banned-words checked).
  *PREMIUM reward. Small.*
- **Free Bounty Reroll** — 1 free weekly swap (bounties cost 25 snouts today).
  *PREMIUM (modest). Small.*
- **Closet Favorites + Filters** — star items; filter by slot/rarity/season/new.
  *FREE — usability fix. Small.*
- **Claim All** — batch-claim ready pass tiers with one reveal. *FREE. Small–med.*
- **Patch-Open Reminder** — opt-in push when the Truffle Patch opens. Player-
  friendly, lifts the co-op. *FREE. Medium. (High value-per-effort.)*
- **"Surprise Me" randomizer** — dress Rosie in a random *owned* combo. *FREE,
  tiny, client-only.*
- **Trophy Case / Stats** — Me-page: lifetime tickles/finds/digs + a gallery of
  earned titles. Makes exclusive titles worth chasing. *FREE. Medium.*

## Battle-pass reward types (loop-safe, ready today unless noted)

- Cosmetics (all slots) · tickle particles · **exclusive season titles**
  (approved) · mystery boxes (`grant_mystery_box`) — all ship-ready.
- **Companion critters** — high-tier prestige rewards (see spec).
- **Nameplates / Board name effects** — biggest flex-per-effort; *needs building.*
- **Removed for good:** tickles (leaderboard pay-to-win) and the stubbed boosts
  (grant nothing).
