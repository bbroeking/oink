# Visit Streaks — UI brief

## One-line promise

When either friend visits, the shared flame between those two pigs stays warm.

## Friend-row presentation

- Show one flame beside the friend's identity, never two directional flames.
- Put the explicit live count inside or immediately beside the flame.
- Use the staged art language already approved for Pair Flames: spark, flame,
  bonfire, then hearthlight.
- When the run sleeps, show a small wisp and the banked longest count. Never say
  who missed, show a countdown, or issue a lapse warning.
- A same-day return visit may celebrate the relationship but never increments
  the count twice.

## Milestones

- Day 30 and day 90 award both players matching, pair-bound cosmetics.
- Rewards are earned only. There are no paid freezes, restorations, or skips.
- The schema may reserve milestone receipt fields before the final wearable art
  is authored, but the UI must not promise an unimplemented reward.

## Accessibility

Read the flame as “Visit streak with [name], [N] days; longest [M] days.” A
sleeping flame reads “Visit streak resting; longest [M] days.” Color and flame
size are reinforcement, not the only state signal.
