# Expo SDK 57 upgrade

Date: 2026-08-12

## Outcome

Tickle the Pig was upgraded one SDK boundary at a time from Expo SDK 52 to
Expo SDK 57. The final runtime is Expo 57.0.12, React Native 0.86.2, React
19.2.3, and TypeScript 6.0.3. The New Architecture is mandatory in this
runtime, so the obsolete `newArchEnabled` toggle was removed.

This is a source and native-project migration only. It did not create an IPA
or AAB, upload a build, mutate a database, or change production data.

## Major changes

- Aligned Expo modules and the React Native ecosystem package set to SDK 57.
- Upgraded Reanimated to 4.5.1 and added Worklets 0.10.1.
- Migrated direct React Navigation imports to Expo Router's SDK 56+ exports.
- Updated notification foreground behavior to the current banner/list API.
- Updated React Native styles and types removed or tightened since 0.76.
- Updated the Jest environment and UI queries for React 19's concurrent test
  renderer and React Native 0.86 host components.
- Upgraded Supabase JS from 2.47.10 to 2.112.3. The old release selected its
  Node/WebSocket entry during an iOS Metro export; the current release exposes
  a React Native-compatible bundle.
- Replaced the old Android API 35 pinning plugin with the SDK 57 Gradle and
  autolinking structure. The project now resolves Gradle 9.3.1 and Android API
  36 configuration.
- Updated CocoaPods, deployment targets, build settings, privacy aggregation,
  and Expo autolinking. The iOS deployment target is now 16.4.
- Preserved the code-less `TTPStickers` extension and its safety comment.
- Preserved the production iOS AdMob application ID in the checked-in plist.
  Production Expo config now refuses both iOS and Android test AdMob IDs.
- Removed the obsolete React Native 0.76 patch and API 35 config plugin.
- Declared Node 22.13 or newer, the supported SDK 57 baseline.

## Verification

- `npx expo-doctor`: 19/19 checks passed.
- `pnpm exec tsc --noEmit`: passed.
- `pnpm exec jest --runInBand`: 124 suites and 1,280 tests passed.
- `pnpm run quality:check`: passed all layout and security gates.
- `pnpm run lint`: exits successfully. Expo 57 exposed 383 existing React
  Compiler-readiness and TypeScript/import findings; these remain warnings so
  the SDK migration does not silently suppress them or require an unrelated
  ref/animation rewrite.
- `expo export --platform ios`: passed; Hermes bundle generated successfully.
- `expo export --platform web`: passed. A web-only rewarded-ad adapter keeps
  the native Google Mobile Ads package out of the browser bundle.
- Clean `pod install`: passed with 130 dependencies and 137 pods.
- iOS simulator compile: passed with Xcode, code signing disabled. The removed
  SDK 52 `EXAppDelegateWrapper` entry point was replaced with the SDK 57 Swift
  Expo app delegate while preserving deep-link and universal-link handling.
- Compiled iOS app plist: verified to contain the production
  `GADApplicationIdentifier`. React Native Google Mobile Ads 14 still prints a
  legacy raw-`app.json` warning, but the checked-in and compiled native plists
  both contain the required identifier. Sentry upload was disabled only for
  this unsigned simulator compile because no upload credential was available.
- Gradle wrapper: resolves Gradle 9.3.1.
- Android compile: not run because this machine has no Android SDK and only
  JDK 11 installed. SDK 57 Android device/build acceptance still requires a
  configured Android toolchain.
- Native plist/privacy manifests and JSON config files: syntax checks passed.

## Follow-up acceptance

Before treating this as a release candidate:

1. Complete the manual/device gates in `docs/RELEASE_CHECKLIST.md`.
2. Exercise sign-in, deep links, push handling, camera QR scanning, audio/video,
   Rive/Skia rendering, purchases, rewarded ads, and the sticker extension on
   a physical iPhone.
3. Configure an Android SDK plus a supported JDK and run the Android app/build.
4. Confirm the Android production AdMob application ID before any Play build.
5. Profile launch and pig-screen memory. Expo calls out an SDK 57 Hermes memory
   regression when Reanimated is imported; evaluate Worklets bundle mode if it
   is visible in Tickle the Pig.
6. Plan a separate cleanup for the Expo 57 lint warnings, then promote the
   compatibility warning overrides back to errors in small batches.
