# Build 68 — 2026-05-22

## Headline

The Season 1 social layer became real. The mechanics existed but were
smeared across four tabs — this build gives them one home (the
Friends hub), an activity feed (the Inbox), a single action door
(UserSheet), and wires blessings + curses so they actually *do*
something. Plus: emoji replaced with hand-generated art everywhere,
the shop economy retuned, and the subscription model untangled.

## User-facing

- **The Friends hub** — one social home with three segments: Friends,
  Inbox, Board. No more hunting across tabs for the social loop.
- **The Inbox feed** — friend requests, trade activity, and the
  blessings/curses you've received, all in one chronological place.
- **UserSheet — the one door** — tapping a friend opens a single
  sheet to ask for tickles, bless, or curse them. No more scattered
  inline buttons.
- **Blessings & curses are consequential now** — they used to just
  record. This build wires the effects: regen swings, the Barn glow /
  miasma, tap misses. A **receiver effect panel** shows what's active
  on you; the cast UI shows every state (ready / sent / already cast
  / spent); a **"while you were away" dialog** greets you on launch
  if someone blessed or cursed you.
- **One blessing + one curse per day** — the daily ritual cap dropped
  from 3 (5 for VIP) to a flat 1 of each, for everyone.
- **Real art, no emoji** — 34 hand-generated icons replace emoji
  across the Inbox, rituals, achievements, release notes, and shop.
- **Achievement reveal** — unlocking an achievement now shows a
  proper celebration modal; it used to unlock silently.
- **Shop prices cut 10×** — every item is now a tenth of its old
  price (the top end went 8000 → 800 snouts).
- **Cosmetics sit better** — a new anchor-relative placement system
  keeps hats/items aligned across screen sizes; auras now render as a
  full backdrop behind the pig.
- **Necklaces & capes removed** — the art never sat right on the pig;
  they'll be regenerated and re-added later.
- The Ask dialog is state-aware — it shows a cooldown or an
  in-progress trade up front instead of erroring after you tap.

## Internal

- **Season Pass + Slop Club** — the four tangled "premium" concepts
  (VIP, "Pro", the battle pass, the sale modal) were redesigned into
  two clean products: a one-time **Season Pass** and the **Slop
  Club** membership. Code landed but **dormant** (`IAP_ENABLED`
  false). Activation + the RevenueCat webhook live on the
  `subscriptions` branch.
- **/deslop cleanup** — dead code removed, duplicate types
  consolidated, weak `as any` casts strengthened (≈260 lines net
  removed).
- **AppleAuth hardened** — debug `console.log`s removed, including
  two that logged the Apple credential / user object.
- **Migration-drift fix** — `update_profile_and_item_count` had
  drifted from the repo on the remote; the regen migration was
  rebuilt from the live definition (`pg_get_functiondef`).
- A standalone web **item-anchor tool** (`tools/item-anchor`) for
  tuning cosmetic placement.
- 109 tests across 13 suites; `tsc` clean (bar 2 pre-existing).
