# Build 81 — 2026-06-06

## Headline

A polish build on top of build 80: the **Closet** gets the refined fitting-room
layout from the claude.ai/design handoff, and **barn visiting** stops *looking*
like it resets when you hop between barns (it never did server-side) — plus the
"a visit spends one of your tickles, and you both get happier" model is now
obvious in the UI.

## User-facing

- **Closet redesign.** Centered header + coin, a cream fitting-room card with the
  live pig preview, and **equip-slot chips that map 1:1 to the sections below** —
  only the slots you actually own items in show (no more mystery empty slots, no
  sideways scroll; they wrap to fit). Section titles are left-aligned. Item tiles
  now carry a rarity stripe + tinted swatch and a clear lilac **"ON"** state.
- **Barn visiting no longer feels like it resets.** The 7-taps/hour-per-barn
  ceiling is *shared* across re-visits within the hour, so hopping A→B→A
  continues toward the same ceiling instead of handing you a fresh session. If a
  barn's pigs are already spent for the hour, opening it now shows **"still
  snoozing — come back later"** instead of letting you start over.
- **Visits spend your tickles, and count for both.** Each tap gives the host one
  of *your* tickles and makes **both** pigs happier — now spelled out in the copy,
  with **both pigs bouncing** on a tap. Out-of-tickles is handled gracefully
  ("let your bank fill back up, then come play").

## Internal

- Closet: `components/ClosetView.tsx` rewritten to match `Closet.html` /
  `ClosetFinal` from the design bundle — slot chips derive from owned-item slots
  (`slotsWithContent`), wrap instead of horizontal-scroll, headers left-aligned,
  refined `ItemTile` (rarity stripe/swatch + lilac ON footer + ✓ badge).
- Barn reset: new read-only RPC **`barn_visit_status(p_target)`** (migration
  `20260602`) returns `taps_left / resting / out_of_visits / balance` (the
  `barn_visits` table is RLS-on/no-policies, definer-only). `BarnVisitModal`
  pre-checks it on mount → `restingOnArrival` / `noTickles` states; session ends
  on the server's `taps_left <= 0` as well as the sleepy roll. Visitor pig shares
  the tickle `bounce`. Builds on the cost-transfer model from `20260601`.
