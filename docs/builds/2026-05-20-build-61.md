# Build 61 — 2026-05-20

## Headline

App renamed to "Tickle the Pig" on iOS home screen + everywhere iOS
shows the app name.

## User-facing

- App label under the home-screen icon now reads **"Tickle the
  Pig"** instead of "ttp".
- TestFlight build list, share sheets, Settings → app list, and the
  notification payload "from" line all read "Tickle the Pig" too.
- No behavior changes.

## Internal

- `ios/ttp/Info.plist` — `CFBundleDisplayName` flipped from `"ttp"`
  to `"Tickle the Pig"`. Display-only override that doesn't affect
  bundle ID (`com.broeking.ttp`), EAS slug (`ttp`), or the Xcode
  project folder (`ios/ttp/`) — all three deliberately unchanged to
  avoid breaking code signing, EAS project linkage, or Xcode build
  config.
- App Store Connect display name + the App Information `Name` field
  still need to be updated by hand in the web console.

## Migrations

None.

## Known issues

- App Store Connect's `Name` field is set by the user, not by the
  binary — must be edited at https://appstoreconnect.apple.com.
