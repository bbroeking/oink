# Build 87 — 2026-06-07

## Headline

Visit & Tickle screen fixes from on-device review: the two pigs + the friend's
background now render, and the two bottom helper texts are gone.

## What changed

- **Both pigs render.** The shared squish animation's `transform` was clobbering
  each pig's `{ scale }` (RN keeps the later `transform`), so pigs drew at full
  300px and clipped to nothing. Now scale + squish compose in one transform list.
- **The friend's background shows.** Painted as an explicit absolute-fill `Image`
  (e.g. freddy's `forest_grove`) instead of `PageBackground`, whose flex nesting
  wasn't painting inside UserSheet's modal overlay.
- **Removed** the "✦ tap a pig to start tickling" nudge and the "ⓘ How visiting
  works" pill (+ the help sheet) per design feedback.

## Internal

- `components/BarnVisitModal.tsx`: `squishTransform` array composed with per-pig
  `scale`; `bgSrc` via `HAT_IMAGES` → absolute `Image`; `content` flex wrapper;
  dropped `PageBackground`, `showHelp`, the nudge/help-pill/sheet.
