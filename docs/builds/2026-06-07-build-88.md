# Build 88 — 2026-06-07

## Headline

Barn-visiting + truffle polish, a new hand-drawn art pass, and two big balance
fixes: pigs no longer sit perpetually sad, and social play finally earns
season-pass XP.

## Gameplay / balance (server — migrations pushed)

- **Happiness rebalance** (`20260612…happiness_rebalance`). Decay was 1.5/hr
  (~36 pts/day) vs a max gain of ~15/4h, so ~90% of live pigs were stuck Sad and
  *no* pig had ever reached Happy. Now: decay **1.5 → 0.5/hr** (~3 days of neglect
  to fall Sad, daily play stays up), window cap **15 → 25**, gains full-strength
  until ~mid so Happy is reachable. Lowering the rate recomputed everyone's live
  happiness upward on deploy (sad pigs 28 → 24 immediately, recovering further).
- **Season-pass XP for social actions** (`20260613…xp_for_social_actions`).
  Previously ONLY home tickles (+1) earned XP, so visiting/gifting set you back.
  Now, via a `grant_season_xp` helper: home tickle **+1 → +3**, visit tap **+5**,
  first dig/day **+3**, first bury/day **+5**, blessing **+5**, curse **+2**.
  Daily-capped where farmable; bank/cooldown-bounded. (Referral XP deferred.)

## Features

- **Barn visit (`BarnVisitModal`)** — pigs are bigger and staggered with depth;
  the host's **full outfit** renders (hat + glasses + held + …), not just a hat;
  the two top counts are now **live tickle totals that tick up** together; single
  clean background (host's), no half/half veil; out-of-tickles message pops over
  the TICKLES bar; a cartoony **shovel dig** affordance near the pigs.
- **Truffles are a shared pot.** Each dig takes 40% of what's left (all of it if
  <5 remain); one dig per visitor. **Bury** lets the host stake 10/20/50 snouts,
  shows a glowing **dirt mound** by the pig with a bury animation, and a **"check
  on your truffle"** sheet (remaining + who's dug).
- **"How to earn XP" card** on the Season pass screen so progress is legible.

## Art — hand-drawn glyph pass (no-emoji, in progress)

- New cozy **snout coin** currency icon (replaces the flat SVG).
- 50-glyph hand-drawn library (`assets/images/glyphs/`, `components/ui/Glyph.tsx`)
  replacing emoji/dingbats. Wired so far: BarnVisitModal, all truffle UI, **Barn
  home** (stat chips, lucky badge, toast, tickle particles), Season XP card.
  Remaining screens (Friends, UserSheet, Shop, rest of Season) still on emoji —
  rolling out screen-by-screen.
