# Build 83 — 2026-06-06

## Headline

Build 82 (push notifications) + the **barn-visit cooldown UI**, the **one-person-
every-3-hours** rule, the **Closet** redesign, and a couple of server-side fixes
(Brian off the leaderboard, zero-cost pass hats re-claimable). This is the build
to **device-verify push on**.

## User-facing

- **Push notifications now work.** (Build 82 enabled the entitlement + APNs key.)
  On this build, opening a social surface (Friends) and accepting the prompt
  registers a token; friend requests / trade answers / barn visits push through.
- **One friend's Barn every 3 hours.** Visiting (tap-tickling) a friend now locks
  you to that one pig for 3 hours — you can keep tickling *them* until the pigs
  tire out, but you can't start on a *different* barn until the cooldown passes.
  The modal shows "Come back in 2h 15m" and a clear explanation. (Replaces the
  old "5 barns/day" budget.)
- **Barn visits don't reset by hopping.** Re-opening a barn you've already
  tickled this hour shows the pigs still resting instead of a fresh session.
- **The Closet redesign** (centered fitting room, slot chips that map 1:1 to the
  sections, rarity-striped tiles, clear "ON" state).
- **Zero-cost pass hats re-claimable.** Anyone who passed tiers 7/18/22 before
  those hats existed can now claim them again from the pass.
- **Leaderboard:** the owner/test account no longer shows on the alignment board.
