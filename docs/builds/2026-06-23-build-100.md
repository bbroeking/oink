with an **animated background** (Northern Lights) equipped — the pig wouldn't

the bottom tabs still worked. Build 100 fixes that. Also: **battle-pass cosmetics

## Barn untappable — the whole screen ate touches (client)

- **Symptom:** with the Northern Lights background on, tapping the pig did
  nothing — no animation, no tickle, no count change. The stat cards and shovel
  were dead too; only the bottom tab bar (rendered outside the screen) worked.
- **Root cause:** `AnimatedBackground` (new this season) stacks full-screen frame
  `<Image>`s behind the page content. On the **new architecture (Fabric/
  Bridgeless)** an absolutely-positioned sibling hit-tests *above* a later flex
  sibling — contrary to the old declaration-order rule — so the frames, filling
  the whole screen with default touch handling, **swallowed every touch** on the
  Barn. Only animated-background users were hit; static backgrounds were fine.
- **Fix:** the frames now carry `pointerEvents:"none"` (in style, the Fabric-
  correct form) plus an explicit `zIndex` so content sits on top deterministically.
  `components/ui/AnimatedBackground.tsx`.
- **Guarded:** `__tests__/AnimatedBackground.test.tsx` fails the build if the
  frames ever become touchable again; `__tests__/SwipeElement.test.tsx` locks the
  pig→tickle wiring.

## Battle-pass cosmetics never enter the shop (client + server `20260675`)

- Tier rewards are **earned only** — they must never appear in the daily drop or
  Browse. This used to rely on the manual `cost = 0` convention; now it's
  **structural and self-maintaining for all future seasons**: a `pass_exclusive`
  flag on `hats`, kept in sync by a trigger on `season_tiers`, excluded in
  `daily_shop()` + rejected by `buy_hat()` regardless of price.
- Client (`shop.tsx`) also hides them from Browse and **degrades gracefully** if
  the column isn't deployed yet (retry-without-column fallback), so the client is
  safe to ship before or after the migration.
- **Needs a DB push:** `supabase/migrations/20260675000000_battle_pass_shop_exclusion.sql`.
  The Barn fix needs no server change.
