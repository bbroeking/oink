# Build 77 — 2026-05-26

## Headline

Build 76 was built (`build-76.ipa` exists locally + sat in
Transporter) but never delivered. Build 77 supersedes it with the
same payload plus the in-app App Store review prompt that lands
at the end of the first Lucky Pig flow.

## Delta vs build 76

- **In-app review prompt** — fires `StoreReview.requestReview()`
  ~1.2 s after the user's first Lucky Pig modal chain settles
  (the 8th-tickle guaranteed trigger for every brand-new player).
  Apple rate-limits to 3 prompts/year per device; our
  AsyncStorage `review_prompted_v1` flag is set before the call
  so we never re-ask the same user.
- TestFlight caveat: Apple suppresses the native dialog on
  TestFlight + Ad Hoc + Xcode builds, so the prompt won't
  visibly appear in this build's TestFlight pass. Confirmation
  that the trigger fires at the right moment comes from the
  Sentry breadcrumb `[review] would fire (Apple may suppress
  on TestFlight)`. On the App Store release after this build is
  approved, real users will see the dialog.
