# Build 74 — 2026-05-25

## Headline

Hotfix on top of 73: iPhone-only binary. Build 73's Info.plist still claimed iPad support (UIDeviceFamily `[1, 2]`), which made App Store Connect demand a 13-inch iPad screenshot at submission time. The existing `ios/` folder's Xcode project had `TARGETED_DEVICE_FAMILY = "1,2"` that overrode `app.json`'s `supportsTablet:false`.

## Internal

- `ios/ttp.xcodeproj/project.pbxproj` — both Debug + Release configs now set `TARGETED_DEVICE_FAMILY = "1"`. The binary's Info.plist will list UIDeviceFamily `[1]` (iPhone), App Store Connect drops the iPad screenshot requirement.

## Migrations

None — pure native build setting change.

## User-facing

Nothing visible. v1 was always intended as iPhone-only.

## Verification

- Pre-build pbxproj greps confirm both build configs are `"1"`
- App Store Connect should accept the iPhone screenshots already uploaded after this build lands + is selected on the version 1.0.0 page
