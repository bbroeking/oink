## Sounder League, Phase 1 (dark until the flip)

- **Weekly war terms**: the season splits into weekly terms; each term every
  Sounder gets ONE scheduled fixture (prefer-unplayed pairing, rematches
  legal this season; the ghost crew fills the odd bye). `advance_war_term()`
  rolls terms hourly via pg_cron — live on prod now, no-ops until the
  `season_2` league row starts (Jul 12).
- **No draws**: every fixture resolves win/loss. Dead-even rope falls to
  most-active-snouts → most-digs → elder-banner (recorded by an AFTER
  UPDATE trigger on the resolve flip — resolve_war NOT carried).
- **The season table**: `sounder_league_standings()` ranks by wins, then
  mud difference, then name. `my_league_state()` powers the placard (term,
  fixture + won/lost, record, position).
- **Sounder League screen** (nee Sounder Standings): Table tab (default,
  Pld/W–L/mud) + Spirit tab; the Elo board retired from view (matchmaking/
  seeding plumbing only).
- **Leaderboard Sounders scope**: league-table rows with the Spirit warmth
  subline. Fixes two latent bugs: the scope was unreachable (generic empty
  state swallowed it) and its toggle tab was labeled "Alignment".
- **Season-tab League placard**: "This term: vs ⟨rival⟩ · N days left",
  season record, table position. Term clock only — the season's end date is
  deliberately never shown.
- **Crew cap 5 → 4** (`20260707000000`): trigger + all four RPC pre-checks
  + client constant. Existing 5-member crews grandfathered (no kicks).
