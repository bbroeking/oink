# Build 94 — 2026-06-10

## Headline

The "frozen at boot" class is closed for real: the popup queue is now a
serializing state machine, so no launch popup can ever present over another —
including the preemption path build 93 left open. Plus the 6-7 easter egg now
fires at every x67 milestone (and its re-prompt bug is fixed before it shipped).

## App frozen at boot — the rest of the fix (P0)

- **What build 93 missed (verifier-flagged residual):** dismissal handoffs were
  serialized, but a HIGHER-priority launch popup arriving while another was on
  screen (e.g. the schism verdict RPC landing 2s after the While-Away dialog
  presented) swapped in the same frame — mounting an invisible iOS modal that
  ate every touch (RN#50152). With 10 popup slots fed by independent network
  calls, multi-dialog boots made this the common case — the "double dialogs"
  reports.
- **Fix:** `components/ui/PopupQueue.tsx` rewritten as an explicit state
  machine (`idle → presenting → draining`, single writer). A presenting→
  presenting transition no longer exists: EVERY exit (user dismiss, preemption,
  trigger dying in background) hides the modal, waits the full 700ms drain,
  then admits exactly one winner. Preempted popups return after the interrupter
  instead of vanishing. Boot popups show strictly one at a time in priority
  order regardless of network timing.
- **Tests:** new `__tests__/PopupQueue.test.tsx` (12 tests) encodes every
  violation scenario from the audit — preemption-drain, mid-drain arrivals,
  want-flicker no-deadlock, same-tick arbitration, achievements advance,
  truffle-sheet round-trip. Full suite 219/219 green.

## 6-7 easter egg — every x67

- Fires whenever the snout count ENDS in 67 (67, 167, 267, 1167…) — never
  6700/6701, where the trailing digits kill the joke. Once per milestone.
- Audit caught a pre-ship bug in the first cut: the dialog handlers still wrote
  the legacy `seen_67` flag, which would have re-prompted every launch for
  anyone sitting at an x67 count. Now records the exact milestone (`seen_67_at`).
