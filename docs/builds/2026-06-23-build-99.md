## Shop "Today" tab was empty (server `20260673` — ALREADY PUSHED ✅)

- **Root cause:** `daily_shop()` is `RETURNS SETOF public.hats` but projected a
  hand-listed 10 columns. A later migration (`20260660`) added an 11th column
  (`war_exclusive`) to `hats`, so the function's rowtype stopped matching and the
  RPC **threw at call time** → the client swallowed the error → the default
  "Today" view rendered the empty state. (Browse uses a direct table select and
  was unaffected.) The classic ALTER-after-def footgun.
- **Fix:** redefined `daily_shop()` to project `h.*`, so the rowtype always
  tracks the table and a future `ADD COLUMN` can't desync it again. Verified live:
  `daily_shop()` now returns 8 items. **Server-only — already fixed for all users
  on prod; no client change needed.**
- Also **unpinned the `soccer_ball`** from the daily drop (it still has no art —
  it rendered the generic "held" wand placeholder; re-pin once art ships).

## Barn 3-hour cooldown is now shown (client)
