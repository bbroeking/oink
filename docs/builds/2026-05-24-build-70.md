# Build 70 — 2026-05-24

## Headline

The Season 1 social loop ships end-to-end. Trade-decline pushes, friend-request pushes, achievement-unlock pushes, bounty-ready pushes, and a generic system-announcements channel close every "what happened" gap. WhileAway aggregates trades + blessings + curses + system messages in one launch moment. New hanging-signs tab bar with bounty-ready badge dot, particle bursts on tickle, particle preview animation in the shop, and the Schism modal now fires at ±50 and ±100 (Saint of the Sounder + Goblin King get real moments). Big build on top of 69.

## User-facing

### Notifications
- **Friend request push** + **acceptance push** — receiver gets a push when a request lands; requester gets one when accepted. Both deep-route to Friends. Inbox grows a sage "+ X accepted your request" card in the passive band.
- **Trade decline push** — "X passed on your trade — try someone else in your sounder." Trade withdraw push for the opposite case. Requester is no longer left to wonder.
- **Achievement unlock push** — pops the moment a tier lands, even if you're offline. Tap → /achievements.
- **Bounty-ready push** — fires the second your progress crosses any active bounty's goal. Plus a red badge dot on the Season tab in the hanging-signs bar.
- **Schism modal at ±50 and ±100** — Saint of the Sounder + Goblin King + Deeply Generous/Greedy now get the dedicated reveal, not just a push. Existing ±25 first-crossing modal unchanged.
- **System announcements channel** — admin-issued messages persist server-side so untokened users still see them in the WhileAway modal on next launch. Used today to backfill a +10 welcome-tickle bonus for 5 recent signups.

### Tickle UX
- **Tap fires a burst** of 7–9 particles instead of a single ♥ / ✦, with per-particle drift, scale, rotation, and duration jitter. Reads as a handful, not a clone.
- **Tickle particles are now equippable** — 8 shop cosmetics (heart, star, sparkle, snout, clover, halo, rainbow, music note). Shop preview shows the looping burst animation instead of a still pig.
- **Two new cartoon-pig laugh sounds** replace the four old oinks. Half as many variants, twice as cute.

### Inbox / Friends
- **WhileAway aggregates trades** alongside blessings + curses. Rose card reads "X answered your trade — +N tickles landed in your barn."
- **Inbox give-trade affordance** — "Give N" button disables to "Need M more" (muted) when balance < amount. Race rejection ("insufficient_bank") returns a precise "you have N, they asked for M" toast instead of a generic retry message.
- **Inbox copy unified** — passive band now reads the canonical ritual blurb ("Warm Tea — 2× tickle regen for an hour.") so the recipient sees what the sender saw when casting.
- **Friends list scrolls** with proper horizontal padding. At-cap rows were getting clipped off the bottom.
- **Leaderboard alignment scope** renders two clearly-separated sections (GENEROUS top N · GREEDY top N) using each side's own 1..N rank, instead of one confusing 1..2N flat list.
- **Hoofprints sheet + ActiveEffects inline pill** route through the shared CleanseModal — a stray tap no longer instantly burns 5 snouts.

### Me page
- **"Your title" section removed** — was a duplicate of the title rendered inline next to the username in the page header. One less click for the same data.

## Internal

- **System announcements** — new `system_announcements` table + `send_system_announcement` / `my_unseen_announcements` / `mark_announcement_seen` RPCs. Wire it from anywhere; the WhileAway modal handles the in-app surface.
- **Admin tickle dashboard** — standalone HTML at `dev-tools/admin-tickles.html`. Sign in with a test-account email, see every user's earned / balance / cap / regen / alignment / equipped hat / last-activity in a sortable table. Backed by `admin_tickle_overview()` RPC, gated to `is_test=true` callers.
- **Hanging-signs tab bar** ships everywhere — wooden rail + per-tab sway loops + swing-in tap animation. Badge slot plumbed through `<HangingSignsTabBar badges={...} />` so any tab can flag pending state.
- **LogBox silencer** for `Unsupported dashed / dotted border` warnings on bridgeless Fabric. Without it Metro accumulated the warning stream into a JSON-RPC buffer until OOM at ~7.5h dev sessions.
- **Sounder UI** still dark-launched behind `SOUNDER_VISIBLE=false`. Backend RPCs continue to run.
