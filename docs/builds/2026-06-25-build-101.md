# Build 101 — 2026-06-25

## Headline

**Titles are earned, not bought.** The shop's Titles tab is gone — all 10 ex-shop
titles now drop from **Achievements**, including a new **Devotion** ladder for
lifetime tickling. Prior buyers keep everything (no refund); a backfill auto-grants
any title a player already qualifies for. Plus: the shop's middle tab is renamed
**Collectibles** with per-category filter icons, and the **barn-visit cooldown
exploit** is closed (server-rolled 3–7 tap cap + an independent 3h per-friend lock).
Also a batch of correctness fixes (friend-request decline, in-app cleanse refresh,
"what happened" timestamps, closet label wrap).

## Titles → Achievements (client + server `20260677`)

- **Removed the shop Titles tab** and its buy path entirely (`app/(tabs)/shop.tsx`:
  the `titles` view, `ShopTitleRow`, `handleBuyTitle`, the `shop_titles` fetch). The
  title **equip** path in the Closet is untouched.
- Server (`20260677_titles_earned_only.sql`): the 10 titles are set `for_sale=false`
  and `buy_title()` is now a hard `not_for_sale` no-op (defensive for stale clients).
  Each title is wired to an **achievement reward** across the engine's ladders, with
  a **new `tickle_volume` category** (lifetime `tickles_earned`) + a trigger so the
  Devotion titles earn as you tickle. A **basic-achievement layer** (snout rewards)
  was added too. A **backfill** auto-grants newly-qualifying achievements with the
  `user_achievements` push trigger suspended (no notification blast).
- **Ready-to-claim badge**: the Account → Achievements row now shows a gold badge
  with the count of earned-but-unacknowledged achievements (`my_unclaimed_
  achievement_count()`), capped at **"99+"**. New **Devotion** filter on the
  Achievements screen.

## Collectibles (renamed shop tab + filter icons) (client)

- "Browse" → **"Collectibles"** (display only; internal `browse` key kept so
  `?view=browse` deep links still work). It reads as the full set of everything
  there is to collect — not a store, not your closet.
- Each category filter chip gets an icon (`Glyph`); "All" gets a sparkles glyph;
  added spacing between the sub-tab row and the filter rail; fixed a latent empty
  "Flags" filter.

## Barn-visit cooldown rework (client + server `20260676`)

- The old 15-min sliding-window cap leaked: drip-tapping never armed the 3h lock.
  Now each visit rolls a **server-side random 3–7 cap**; once spent, that friend is
  **locked 3h, anchored to the cap-hitting tap** (re-entry can't reset it). The
  daily cap was dropped (the per-friend gate is the real ceiling).
- Client (`BarnVisitModal.tsx`): server owns the cap; **live 1-second countdown**;
  the lock shows immediately on the exhausting tap.

## Correctness fixes (client)

- **Friend-request decline** now sticks — was calling the outgoing-only
  `cancel_friend_request` (0 rows for a receiver); now `remove_friendship`.
- **Cleanse refreshes the Barn instantly** — a shared `ActiveEffectsProvider`
  replaces four isolated `useActiveEffects` instances (one realtime sub, not four).
- **"What happened" feed** shows a per-row timestamp + a Load-more (up to 100).
- **Closet "Background" label** no longer wraps (shrink-to-fit, one line).
- **Auth "Invalid Refresh Token"** dev toast suppressed (benign, self-healing).
