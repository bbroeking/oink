# Build 85 — 2026-06-06

## Headline

Build 84 + the post-review polish on barn visiting. Same feature set as 84 (push
notifications, Visit & Tickle redesign, 3-hour visit rule, Closet redesign,
re-claimable pass hats, referral auto-cutover) — this build just carries the
review fixes. **Supersedes 82–84.**

## What changed since build 84

- **Accurate nap-screen copy.** When you open a friend's Barn whose pig is just at
  its hourly tap ceiling (but you're *not* cross-barn locked), the screen no longer
  falsely says "3h until you can visit again" — it tells you the pig's resting and
  that you can still go tickle another friend. The real 3-hour cross-barn lock
  still shows its exact remaining time.
- **Exact "YOUR TICKLES" refill timer.** The countdown now uses your real regen
  period (`regen_seconds` from `barn_visit_status`, migration `20260608`) instead
  of a hardcoded display cadence — correct for happy/VIP players.
- **Dead code removed** (`PIG_CANVAS`).

## Internal
