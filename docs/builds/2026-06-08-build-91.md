# Build 91 — 2026-06-08

## Headline

Blessings: raised the daily cap to 3 (matching the in-app promise) with a visible
"N of 3 left + reset" counter, and made the barn-visit truffle dig far easier to
find and tap.

## Blessings — cap 1 → 3 + visible counter

- **Root cause:** `send_blessing` enforced `cast_cap = 1` (from the
  `one_ritual_per_day` migration), but the copy promised "bless up to 3 friends."
  So every blessing after the first returned `daily_cap` and silently did nothing
  — "blessings aren't going through" (e.g. freddy: 11 friends, 1 sent, capped).
- **Fix (server, migration `20260614`, pushed):** `send_blessing` cap → 3 (the
  per-pair-per-day unique index still blocks blessing the same friend twice;
  curses stay at 1). New `ritual_status()` RPC returns used/cap for blessings +
  curses.
- **Fix (client, `RitualPicker`):** the ready state now shows "N of 3 blessings
  left today · resets in Hh Mm"; the Cast button disables at 0; the count ticks
  down per cast; the spent screen says "All 3 blessings used today."

## Truffles — easier to find & dig when visiting

Reports of trouble finding/digging truffles in other barns. The dig logic was
correct; the affordance was just easy to miss (small, unlabeled, corner). Made
the dig spot prominent: an **attract pulse** ring to draw the eye, a clear
**"Dig for a truffle!"** sun-yellow pill (was a tiny "Dig!"), a bigger shovel, and
a larger tap target (hitSlop 24). (Note: only barns whose host has *buried* a
truffle show it — currently ~1/3 of barns.)
