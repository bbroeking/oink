# Build 71 — 2026-05-24

## Headline

Bounties grow up — pool from 6 to 11 with new luck/reactive/distinct-friend mechanics, a per-slot reroll for 25 snouts, and lighter card UI. Achievements rebuilt: 17-item catalog across Generous/Greedy/Social with a redesigned page (filter chips, Ready badge, gold Claim ✦ button on earned cards). Champion poster always shows the tickle count. iPhone-only ahead of App Store submit. On top of 70.

## User-facing

### Bounties
- **Pool 6 → 11.** Five new bounties join the rotation:
  - **Lucky Hog** — Hit a Lucky Pig this week (+100)
  - **Well-Wished** *(got_blessed)* — Receive 2 blessings (+100)
  - **Cleanser** — Cleanse a curse (+75)
  - **Patron** *(bless_distinct)* — Bless 3 different friends (+150)
  - **Hexsmith** *(curse_distinct)* — Curse 3 different friends (+150)
  Same 3-active-per-week rotation; 11-week cycle through every code.
- **Swap a bounty for 25 snouts.** Small muted "Swap · 25" pill on each in-progress card. Per slot, once per week. Swap pulls from the 3 inactive bounties so you always get a fresh challenge.
- **Description text now visible on cards.** Server-side description ("Fulfill 3 trade requests this week.") was previously in the data but never rendered — players only saw the cryptic title. Fixed.
- **Storybook confirm dialog** replaces the bare iOS Alert on Swap. Paper sticker / ink shadow / lilac confirm button — matches the rest of the app's modal family. New reusable `ConfirmDialog` component.

### Achievements
- **17 achievements across 3 categories.** Grown from 8 trade-only:
  - **Generous (6)** — Open Hand, Free Trotter, Bacon Bountiful, Hog of Hearts, Soft Heart, Saint, Halo Bearer
  - **Greedy (6)** — Hungry Hog, Trough Sniffer, Bottomless, Glutton King, Hexsmith, Lucky Lover, Goblin King
  - **Social (5)** — First Friend, Small Sounder, Growing Herd, Full Sounder, Well-Wished
- **Renamed the original 8** to match the design ("Open Hoof" → "Open Hand", "Snout Saint" → "Free Trotter"). IDs unchanged; claim history persists.
- **Redesigned page**:
  - Stats line: `★ N/M unlocked · K ready to claim` (K in accent when > 0)
  - Filter chips: `All / Ready (red badge) / Generous / Greedy / Social`
  - **Ready cards**: cream tint, red `!` over the icon, "earned · +N snouts" body, gold **Claim ✦** button (acknowledges the unlock; reward was already auto-granted on threshold crossing)
  - **In-progress cards**: description text, category tag top-right, progress bar, `N/G · reward · Title: X` line
  - **Done cards**: paper, dim, tiny ✓ bottom-right
- **Retroactive backfill.** Every existing user who already hit a new ladder's threshold (e.g. 8 lifetime Lucky Pigs, 1+ friend) gets the achievement granted immediately — no waiting for their next action to trigger a check.

### Leaderboard
- **Champion poster always shows the tickle count.** Previously the count vanished when the leader had a hat equipped (which is almost always). Now: `♥ 12,345 · wears Halo` — count first, hat secondary, single-line via middot.

### App Store prep
- **iPhone-only.** `supportsTablet: false` ahead of submission. Drops the iPad screenshot + iPad layout requirements.
- **Screenshot helper script** added at `dev-tools/capture-screenshot.sh` for App Store screenshot capture from a 6.7" sim.

## Internal

- **New SQL functions / RPCs**:
  - `reroll_bounty(bounty_code text)` — per-slot weekly reroll, race-safe, charges 25 snouts atomically
  - `my_weekly_bounties()` rewritten — returns `slot_code` + `rerolled` alongside the existing fields; applies rerolls when computing the 3 visible bounties
  - `notify_ready_bounties()` rewritten — pool definition expanded to 11 codes; triggers added for `daily_lucky_claims` INSERT + `curses` UPDATE OF cleared_at
  - `try_claim_achievements()` rewritten — 7 new progress categories (bless_distinct, curse_distinct, alignment_positive, alignment_negative, blessings_received, friend_count, lucky_count)
  - `my_achievements()` rewritten in LANGUAGE sql — adds `display_category` field, dodges plpgsql OUT-param/column name collision
- **New tables**:
  - `user_bounty_rerolls(user_id, week_start, slot_code, new_code, snouts_paid, rerolled_at)` — composite PK enforces one reroll per slot per week
- **5 new achievement triggers**: blessings INSERT, curses INSERT, friendships INSERT/UPDATE status, profiles UPDATE alignment_max_*, daily_lucky_claims INSERT. Each wrapped so a check failure can't roll back the underlying write.
- **`achievements.display_category`** column — decouples technical category (what the claim engine switches on) from the player-facing group.
