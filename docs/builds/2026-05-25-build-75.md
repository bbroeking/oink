## Headline

Build 74 never produced a binary — four consecutive `pod install` runs
hit the pnpm + CocoaPods `Pathname#realdirpath` null-byte flake.
Build 75 is the same submission package (block/report/delete +
iPhone-only pbxproj from build 74), retried with the pod-install
mitigation from session memory.

## Pod-install mitigation

From session memory ([[project_pod_install_flake]]):

```bash
cd ios
rm -rf Pods Podfile.lock
COCOAPODS_DISABLE_STATS=true pod install
```

If `eas build --local` still trips the null-byte error during its
own internal `pod install` pass, the workaround is to pre-install
pods with the env var set, then re-run the build.
