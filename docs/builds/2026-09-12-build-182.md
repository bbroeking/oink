## Headline

Digging opens and closes using each player's server clock, even when the phone's time is incorrect.

## User-facing

- Home and Season share server-based Feeding countdowns and phase boundaries in the player's effective timezone.
- Device clock changes no longer open a Feeding early or expire the already-dug flag early.
- Foreground, timezone changes and window rollover refresh the clock; an existing dig retains its server-issued window deadline.

## Internal

- Added a session-scoped monotonic server clock with per-user phase snapshots and ordered network responses.
- Active screens wake at exact phase boundaries and refresh server state each active minute.
- Timezone registration refreshes the matching server clock; late requests and cache hydration cannot overwrite newer account state.
- Real digs require an established server clock; a failed initial refresh returns a retryable refusal. Expired boards cannot submit into a new window, and account switches cannot submit another account's board.
- Source is frozen separately from active main-checkout work. Native/runtime versions and production configuration remain build 181's locked graph.
- No new in-app What's New modal for this validation-only timing patch. TestFlight acceptance text is updated separately.
