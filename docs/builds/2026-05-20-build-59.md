# Build 59 — 2026-05-20

## Headline

The Sounder — referral program, leaderboard, and a much more visible
Friends section.

## User-facing

- **The Sounder** — share your invite link to grow your sounder.
  Every friend who installs + plays ≥ 50 tickles earns BOTH of you
  500 snouts.
- **Sounder titles** — earn lifetime title rewards as your sounder
  grows: Sounder Initiate (1), Sounder Scout (3), Ambassador (5),
  Drove Captain (10), Sounder Sovereign (25), Crown Hog (50).
- **Sounder leaderboard** — top recruiters ranked by sounder size.
  Reachable from the new "Your sounder · N" card on Account.
- **Account reorganized** — Sounder + Friends now sit immediately
  below your code card, above Pro/Restore, so they're discoverable
  without scrolling past the subscription pitch.
- **Tickle Trade** — request 1-5 tickles from any friend; when they
  fulfill, you owe 2× back when you say thanks. Manage via the 🤝
  pill bottom-right on the home screen.
- **Friend codes (discriminators)** — every account now has a 4-digit
  code (`Brian#4075`). Your code is on the Account card; codes power
  the new autocomplete in the Friends "Add" tab.
- **Friends redesign** — three tabs: Friends / Pending / Add. Live
  autocomplete by username, accept/cancel incoming + outgoing.
- **What's new modal** — v1.2.0 entry auto-pops on next launch for
  everyone covering all of the above.

## Known issues

- `Friends.tsx` request-tickle flow uses `Alert.prompt` (iOS-only).
  Replace with an inline Sticker-styled modal before Android.
- `attribute_referral` with a NULL discriminator silently fails (SQL
  NULL semantics). Practical risk = legacy share links only; new
  links always include the discriminator.
- Potential race condition in the milestone trigger if two concurrent
  tickle updates both cross 50 — would roll back one tickle. Wrap
  `check_referral_milestones` body in an exception block for the
  next pass.
