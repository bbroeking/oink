# Build 72 — 2026-05-25

## Headline

Reporter-found 6-7 freeze fixed (modal swap + safety reset). Trade-send 24h cooldown no longer triggered by cancelled trades. Landing flow rebuilt with the new Rosie sprite as the hero across splash + sign-in + name-pick + loading. PigStage extracted so the Barn and the shop preview share one renderer (single source of truth for anchors + z-order). Shop bento simplified to hero + wide cells only, daily drop now includes owned items.

## User-facing

### Bug fixes
- **6-7 celebration freeze (reporter-found).** After hitting 67 lifetime tickles and tapping "Six seven!", the screen could lock up — pig stuck in the "happy" anim state with all taps silently blocked. Two fixes: the prompt uses the in-app `ConfirmDialog` (no more system iOS Alert in a storybook context) and `SwipeElement` adds a 3-second safety timer that force-resets pigAnim back to idle if the animation callback drops.
- **Trade send "phantom cooldown."** Users couldn't send tickles for 24h after a trade was declined or withdrawn, even though no actual exchange happened. `request_tickles` now only counts `status='fulfilled'` rows toward the 24h pair cooldown — cancelled trades don't lock anything.

### Landing + loading flow — Rosie as the hero
Every screen between app-launch and the Barn now shows the same Rosie players will meet on the home screen. Previously the splash + sign-in + name-pick all used an AI-illustrated pig in front of a red barn, then the Barn revealed a totally different Rosie sprite.
- **Native splash** — cream backdrop with the new `idle_1` Rosie composited at 1284×2778. Old splash kept as `splash-art-v0-backup.png` for revert.
- **Sign-in (SupaAuth)** — Rosie hero centered, "★ tickle the pig ★" kicker, "Meet Rosie" title, Apple sign-in in a paper-sticker card pinned to the bottom.
- **Name-pick (UsernameSetup)** — same hero treatment, "What should Rosie call you?" prompt, storybook input card.
- **Loading state** — replaces the previous bare-black-screen flash with cream + Rosie + "★ saddling up ★" + spinner. Reads as a continuation of the splash instead of a momentary crash.

### Shop polish
- **Bento layout simplified** — every cell is now at least 2 grid units (hero 2×2 or wide 2×1). The original 1×1 squeeze that truncated names to "Sparkl..." and Buy buttons to "W" is gone. Three rotating templates pick a layout per day.
- **Item card readability** — 2-line name wrap, adjustsFontSizeToFit fallback, font 15 → 13, tighter padding so the action button always fits.
- **Daily drop includes owned items.** As a player's collection grew, the daily pool was shrinking toward "same 5 unowned items every day." Now owned items rotate in too; the card branches on ownership and shows Wear / Take off instead of Buy / Not enough. Pure-random over the full catalog.
- **Browse view drops the Buy/Today-only button** — Browse is a catalog, not a shopping surface. Wear/Take off still show for items you own.

### Preview modal
- **Item placement matches the Barn exactly.** The preview was computing item positions from `HAT_OVERLAYS` (legacy absolute) while the Barn used `HAT_REL` (anchor-relative). After the new Rosie sprite swap, this two-store split meant the preview drifted out of sync. The preview now consumes the same data + the same renderer (`PigStage`) as the Barn — anchor re-tuning via the `/item-anchor` tool flows to both surfaces from one place.
- **Auras render WITH the pig** (already correct, confirmed).
- **Backgrounds stay standalone** (already correct, confirmed).
