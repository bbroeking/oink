## Headline

Barn tickling is faster, lighter on the network, and responsive on poor
connections, packaged with the current Expo 57 TestFlight workspace.

## User-facing

- Rapid Barn tickles now update the visible balance and earned total
  immediately instead of waiting for a slow network response.
- A rapid burst no longer sends more core mutations than the locally visible
  tickle balance, and failed requests roll back before reconciling with the
  server.
- The Barn uses fewer auxiliary reads during a tickle burst and renders heart
  particles with fewer React state updates.
- Player digging stories and the Mote Machine are present in the current
  workspace and therefore ride this artifact; their production migrations are
  already applied.
- Sounders support eight pigs and the current Great Hunger/Season tickle fixes
  from build 175 remain included.

## Internal

- Core 20-tap path reduced from 80 to 22 common-path server operations:
  cached session identity, one coalesced `home_stats` read, and one throttled
  pass-event read after the required tickle mutations.
- A 7–9-heart burst now uses two React state commits instead of 14–18, and
  direct font/icon imports reduced the measured iOS export by 68 modules,
  32 assets, and about 4.7 MB versus the recorded baseline.
- A deterministic 2.5-second-RTT benchmark covers immediate feedback,
  synchronous balance admission, and failed-request rollback.
- Expo SDK 57 / React Native 0.86 / React 19 and the Nitro-based Rive runtime
  from build 175 remain part of the native workspace.
- Full measurements: `docs/performance/2026-08-25-performance.md`.

## TestFlight “What to Test”

On a physical iPhone, rapidly spend a full tickle bank on a normal connection,
then repeat under Network Link Conditioner at roughly 2.5 seconds RTT. The
balance and earned total should react immediately, only the visible balance
should be accepted, a dropped request should roll back, and foregrounding the
app should reconcile to server truth without duplicate pass notices. Also run
the complete Expo 57 smoke from build 175 and verify player digging stats, the
Mote Machine, Sounder capacity, season rewards, purchases, auth, deep links,
push routing, camera, audio/video, Rive/Skia, reduced motion, and offline/
reconnect behavior.
