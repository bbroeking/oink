# Build 76 — 2026-05-26

## Headline

The big-bang build. 27 commits since build 75 covering: the full
six-candidate architecture review, referrals end-to-end (spec +
schema + UI + push), real artwork for the six season-pass +
referral hats that had been silently emoji-fallback, three
genuinely-broken-in-prod gameplay bugs surfaced + fixed during the
review, and a one-line process doc that consolidates the placement
workflow under a single standalone tool.

## User-facing

- **Six new hats with real art:**
  Bunny Ears, Crown of Leaves, Devil Horns, Cat Ears, Astronaut
  Helmet (the season-pass tier rewards earned via
  `claim_tier_reward`) and the Messenger Hat (the 3-completed-
  referrals milestone). Previously these rendered as a generic
  category-icon placeholder; now they're flat front-view
  storybook sprites placed correctly on Rosie's head.
- **Referrals shipped:** every player has a persistent
  `ROSIE-K3T9`-style code surfaced on the Account screen ("Refer
  friends" card — code + Copy + Share). New users see a "got a
  friend's code?" step in onboarding that pre-fills from
  clipboard or the deep-link handler. Inviter gets +100 snouts +
  Messenger Hat at 3 completed referrals; invitee gets +50 on
  redemption. Inviter credit only fires once the invitee crosses
  both 100 lifetime tickles AND 3 distinct active days — keeps
  alt-account farming uneconomic. Spec at `docs/referrals.md`.
- **Gifted trades visible in Inbox:** when you fulfill someone's
  tickle request, a new sun-gold ★ row appears in the Inbox's
  passive band reading "you gifted X N tickles" — mirrors the
  receiver-side "your trade was answered" row. Before this you
  saw a 2.4s toast and then no record; now you can scroll back.
- **Sunbeam blessing actually works:** the 40% boost to your
  next Lucky Pig roll was a dead code path in production. The
  effects state in Barn only hydrated through a dev-only
  fallback that never fired in prod. A player with `sun_beam`
  active now actually gets the boost. (Same shape of bug also
  unlocked phantom-itch curse + BarnOverlay alignment theming.)
- **Phantom-itch curse actually bites:** the 33%-of-taps miss
  was also dead. Now a cursed player sees occasional "your tap
  slipped" toasts for the duration of the curse.
- **BarnOverlay reflects alignment:** the Greedy / neutral /
  Giver overlay theming on the Barn was stuck at "neutral" for
  every player — `setAlignment` was only called in the dead
  fallback path. Now hydrates on every focus.
- **Ritual blurb copy fixed:** Sun Beam and Phantom Itch text
  descriptions had been describing a different mechanic than the
  code implemented. Updated to match reality.
- **Friends → Add suggestions row populated:** the
  `suggested_users` migration finally applied to remote, so the
  Add tab actually shows three random non-friend profiles. Has
  been empty in TestFlight since the feature shipped.

## Internal (architecture review)

Six deepening passes from the `/improve-codebase-architecture`
audit; all landed atomically with their tests:

1. **Active-effects layer** — `hooks/useActiveEffects` +
   `utils/activeEffects`. Three components were each fetching
   `my_active_effects`, re-declaring the `Effect` type, and
   hand-rolling their own countdown formatter. One hook now owns
   fetch + realtime + cleanse; three render surfaces are pure
   consumers. Quietly fixes the Inbox panel's missing-realtime
   bug.
2. **RPC façade** — `utils/rpc.ts` with one generic
   `rpc<T>(name, params?): Promise<T | null>`. 67 hand-rolled
   casts across 24 files collapsed; errors now flow through
   `log.error()` to Sentry instead of vanishing into ignored
   `error` fields.
3. **Friendships module** — `utils/friendships.ts` owns the
   `FriendshipStatus` type, `FRIEND_CAP_LIMIT`, the
   `friendActionMessage` error-to-copy mapping, and typed
   wrappers around 6 RPCs. The friendship contract used to be
   smeared across Friends, UserSheet, Leaderboard, and Inbox.
4. **Barn extraction** — `components/Barn.tsx` shrank 1471 →
   1089 LOC across four atomic commits. Five hooks now own its
   subsystems: `useHomeStats`, `useStipend`, `usePassEvents`,
   `useLuckyPig`, `useActiveEffects` (consumed too). Pure
   `rollLucky` math in `utils/luckyPig.ts` with 10 unit tests.
5. **IAP adapter pair** — `utils/iap.ts` refactored to an
   interface + two plain-object adapters (`realIAP` + `noopIAP`).
   The `IAP_ENABLED` kill switch decision moved from 10 per-
   function branches up to one module-init choice. Same
   public surface; runtime behavior preserved.
6. **Rarity tokens** — `RARITY_GRADIENT` was duplicated in
   shop.tsx and ItemPreviewModal.tsx with divergent colors.
   Consolidated to one source of truth in `constants/theme.ts`;
   modal's solid swatch is derived from gradient[0].

  `bone_necklace`, `ermine_cape`, etc.) still have no artwork —
  they don't fit the 2D-front pig silhouette cleanly. They'll
  continue rendering with their emoji glyph fallback if rolled
  into the daily shop. Catalog cleanup is queued as a separate
  migration when desired.
- Universal Link domain hosting (`apple-app-site-association`
  JSON at `ticklethepig.com/.well-known/` + `associatedDomains`
  in `app.json`) is NOT in this build. Referrals work fully via
  in-app code entry; the share button uses a system share sheet
  with `https://ticklethepig.com/r/<code>` text, but tapping
  that link won't deep-link into the app until Phase 2 of the
  referrals spec lands.
- IAP stays `IAP_ENABLED=false`. Slop Club + Season Pass remain
  dormant; the adapter refactor was internal-only.
