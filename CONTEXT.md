# Project context

Anchors for the codebase's architectural vocabulary. Started during the architecture review that produced `hooks/useActiveEffects.ts` — kept short so it stays load-bearing rather than aspirational. Append rather than rewrite; remove only when a term genuinely no longer maps to the code.

## Domain

- **Tickle the Pig (TTP)** — cozy mobile game built on Expo 52 + Supabase. Daily blessings/curses and trades change a player's alignment (Greedy ◄──► Giver); Season 0 (the greedy/generous era, renumbered 2026-07-06) builds toward a Judgement Day finale.
- **Web First Session** — the authenticated, browser-playable opening of TTP for a new player, using their real synchronized account state and handing them into the normal web game. It is not an unauthenticated preview, marketing tour, or App Store funnel.
- **Ritual** — the _sender-side_ act of casting a blessing or curse on another player. Lives in `utils/rituals.ts` (metadata, daily rotation) and `hooks/useRitualCaster.ts` (status, cast, per-target outcome — the one caster every surface uses). Cast surfaces (2026-09-12): the friend row's one-tap bless/curse doors, the Inbox's bless-back on a received blessing, and the profile sheet's `RitualPicker` (opens on Bless for friends). A landed cast shows the **ritual bubble** (`components/ui/RitualBubble.tsx`, `showRitualBubble`, host at app root) from the doors and the bless-back; the picker keeps its in-sheet sent beat because its sheet is a native Modal that would cover the bubble. Refusals stay on the fail toast. The `sent` outcome carries `ritual` (the server's kind) so the bubble draws what was actually cast. (2026-09-15)
- **Active effect** — the _receiver-side_ counterpart: a blessing or curse currently in force on the caller, surfaced by the `my_active_effects` RPC.
- **Hoofprints** — the player-facing display name for active effects ("Hoofprints on you"). Internal code uses the technical name; the term _Hoofprints_ belongs to UI surfaces (sheet titles, section headers).
- **Sounder** — the player's crew and social home ("Your Sounder"), capped at eight pigs. Members dig separate copies of the same Truffle Patch during a Feeding; their asynchronous participation unlocks Sounder Bonuses, more digging time for later diggers, shared milestones, and collective rankings. One Sounder per pig; led by one crown-wearing leader. _Avoid_: friends list, live multiplayer party.
- **Recruits** — the referral downline: the pigs a player brought into the game, the recruiter board (`app/recruits.tsx`, titled *Your Recruits*) and the reward ladder beside it (`app/recruits-progress.tsx`). The word `sounder` belongs to the CREW everywhere — in routes, files, deep-link params and copy — so nothing about referrals wears it. (Both routes were `/sounder` and `/sounder-progress` until 2026-09-11; the collision with the Friends hub's `?seg=sounder` is finding B-15.) _Avoid_: Sounder, downline, the referral Sounder.
- **Feeding** — a recurring opportunity during which the Great Hungerer gorges and each pig in a Sounder may submit one Truffle Patch dig. A Feeding has an open phase for digging and a guarded phase for waiting; missing one has no penalty.
- **Truffle Patch** — the personal scratch-to-dig board available once per Feeding to each Sounder member. Sounder members receive the same base layout but dig their own copy independently; it is not a shared live board.
- **Dig** — one submitted Truffle Patch attempt. A player rubs or shoves mud away until they stop or the Great Hungerer notices; everything fully uncovered before submission is banked.
- **Dig Find** — one fully uncovered, banked object from a Truffle Patch: a truffle cluster, shimmer pocket, junk object, or relic. Stones are inert and do not count. _Avoid_: Adventure Find when the distinction matters.
- **Shimmer Pocket** — an occasional Dig Find that releases one Mote and contributes one Find. _Avoid_: treating its floating particle burst as the reward itself.
- **Mote** — an earned consumable uncovered in a Shimmer Pocket or claimed on the Prestige Path from permanent Wallow Rank 3. Each eligible lap adds one Mote at tiers 3, 8, 13, 18, and 23; reached tiers in the current lap remain claimable for existing players, without backfilling finished laps. One Mote powers a guaranteed Reveal. The locally implemented, server-gated Wager mode stakes 1, 3, or 5 earned Motes and can return nothing. _Avoid_: purchased stakes, decorative particle count, cash-out, or confusing gross returned Motes with net profit.
- **Mote Machine** — the earned-resource machine with a preserved guaranteed Reveal and a locally implemented Wager mode. Reveal spends one Mote for Clockwork Acorns; Wager explicitly allows a loss, returned stake, or versioned Mote/Acorn payout. Wager remains disabled until the compatible authored runtime and rollout gates pass. Rive performs the confirmed result but never selects or grants it. _Avoid_: purchasable plays, cash-out, or success wording for a loss or neutral return.
- **Contraption** — a named collectible helper manifested by the Mote Machine and represented by its own recognizable icon and visual form. The first win of its distinct charging resource permanently unlocks it and provides its first charge; repeat wins add more of that resource to the Contraption Inventory. Spending charge activates a clearly timed service measured on a day- or week-scale rather than one isolated action. The player configures it to perform one bounded job while they are away, with an understandable verb, policy, limit, and stopping condition. _Avoid_: a universal Charge currency, a global passive percentage, invisible automation, or an unbounded substitute for playing.
- **Contraption Inventory** — the player's collection of unlocked Contraptions and the stored quantity of each Contraption's own charging resource. A resource is never stored for a locked Contraption because its first unit unlocks that Contraption immediately. This inventory is separate from worn cosmetics, Adventure Bag items, and Ramble gear. _Avoid_: duplicate Contraption instances or one shared fuel balance.
- **Auto-Tickler** — a Contraption that, while its timed service is active, automatically spends Tickles only when the player's balance is above their personal Tickle cap minus five. It stops at that dynamic reserve and resumes when regeneration raises the balance above it, preserving most of the bank for manual play while preventing capped regeneration from going to waste. Every automatic tickle counts toward `tickles_earned` and competitive standings and awards the normal Snout, making it real earned play; it does not advance or preserve Streak. _Avoid_: a fixed reserve amount, draining the player's full bank, excluding its activity from earned-Tickle totals, creating a reduced-value class of automatic tickle, or substituting automation for the Streak's manual-engagement requirement.
- **Sounder Bonus** — one extra Golden Truffle awarded to a qualifying truffle-finding dig when at least one other Sounder member also submits during that Feeding. Participation can happen in either order; members do not need to be online together. _Avoid_: Echo, Echo caught.
- **Happiness** — a pig's medium-term care state on a **20–80** band, driven primarily by **your own tickling consistency**: it decays over time and is raised by tickling, so regular small sessions keep it high while neglect lets it fall to genuinely **sad**. Friend-acts (visits, tickles received) can raise it too but are only **25% as effective** as your own tickling. Multiplies tickle regen rate (faster when happy). Curses do _not_ lower it — ritual-effect debuffs are a separate short-term axis. (Supersedes the friend-acts-only, floored-at-30 design in ADR 0001.)
- **Mood** — the visible readout for happiness, and the _only_ one: the pig's **idle sprite itself**, never a number/meter/label. Three bands map to the three sprite sets — **Sad** (`sad`), **Content** (`idle`), **Happy** (`happy`). **Mood drives Rosie's resting idle animation everywhere she renders** — Barn, Visit screen, Closet — except when she's mid-animation (tickle bounce, lucky-pig, jump). The one carve-out (2026-07-16): the **shop item preview**, which is a product shot of the _item_ — the pig freezes at the rest frame there (the anchor-tuning pose) so the cosmetic reads exactly; mood does not display in that surface. The "sad sprite when out of tickles" behavior is sunset; an empty tickle bank is the heart counter's job, sadness is happiness's. Friends see your mood when they visit — the "Jen's pig looks sad — I should go tickle it" social pull.
- **Visit** — a social act distinct from blessing/cursing/trading: opening a friend's pig view to see their equipped look + mood and **tap-tickling their pig**. Since 2026-09-14 the **host's pig is the only tickle target** — your own pig is the guest (a tap waves; it never calls the server) — and the two pigs **face each other** on one ground line: each is given a `PigStage facing` (guest right, host left) and, at rest, **turns** — the three-quarter `face` / `face_sit` sprite families, drawn looking right and mirrored for the host (2026-09-15; before that the host was only mirrored). Each tap raises the host's pig (tickles + 25% happiness) and your own pig (tickles + full happiness); the count moves optimistically and reconciles to the server. A [[Satchel]] delivery is a separate act on the same screen. A fresh visit receives a server-rolled **3–7 tap** cap; after it is spent both pigs get [[Tired]], and that friend stays locked for 24 hours from the visit start. Separately, a player may open three distinct fresh Barns per rolling Wallow-scaled window (8 hours at W0 down to 3 hours at W5+).
- **Visit Streak** — the shared consecutive-visit count attached to one unordered pair of friends. Either pig's first qualifying Visit keeps the pair's flame alive; both visiting does not create two credits. A qualifying visit at least 24 hours after the last credit extends the flame when it lands within 36 hours, while a later visit rekindles at day one. The live flame and its explicit count appear on the friend row, and the longest flame is banked permanently. This replaces Pair Flames: blessing, curse, and trade actions do not advance it, and the UI never assigns blame for a sleeping flame. _Avoid_: a global “visit anyone” streak, directional duplicates, or two credits in one day.
- **Tired** — the in-fiction cap on a [[Visit]]. After 3–7 taps the **host** pig naps (the `tired` sprite, a zzz, and the count chip under it turns into a "tickled out" tag — the durable signal; the toast is only the moment), a "come play another time" line shows, and the action bar offers Head home. The visitor's pig stays awake and beams — the one you can't tickle is the one asleep (2026-09-14; before that both pigs tired). Visit-only — the home pig never tires (it must spend its full tickle bank for snouts). A tap on the napping pig wobbles the tag rather than dying silently.
- **Streak** — a player's consecutive-engagement state, measured as the number of "personal days" in which they manually tickled within a rolling 36-hour window since their last streak credit. Auto-Tickler activity never advances or preserves it. Multiplies tickle regen alongside happiness, blessings, and curses on an independent axis: streak rewards loyalty regardless of social activity (where [[Happiness]] rewards friend-acts). The regen benefit caps at day 30 while the visible consecutive-day count continues; a gap of 36 hours resets the live count. Its canonical display is an explicit consecutive-day flame badge under the Home/Barn spendable Tickle-bank counter (the flames that used to flank the counter itself were dropped 2026-09-12: on a two-up ticket they truncated the bank count); this replaces the retired Garden metaphor. A player may deliberately share their current Streak, but it is not automatically exposed to visitors or friends. Internal/technical name is `streak`; player-facing surfaces use a cozier label (e.g. "Devotion").
- **Barn** — the player's home in TTP. Bifurcates into [[Exterior]] (the outdoor scene + clickable barn structure) and [[Interior]] (the decoratable indoor space). The current home-screen tab is being repositioned as the Exterior; the Interior is reached by tapping the barn structure.
- **Exterior** — the outdoor scene around the Barn: Rosie on a painted ground plane, with the existing background system as the outdoor scenery (pasture, beach, forest, etc.). Houses ambient effects and the entry point to the [[Interior]]. Since 2026-09-13 it is **two corners and one button**: the **earned stamp** (`components/EarnedStamp.tsx`, top-left, the lifetime total — the permanent number), the **tickle coin** (`components/TickleCoin.tsx`, top-right, the bank — the live number, with the streak on its shoulder, the regen clock as a hand line and any lucky-pig / wallow ribbon under it), and the **Barn button** (`components/BarnButton.tsx`, bottom-right) whose face is the default action — the shovel while the Truffle Patch is open, the barn door otherwise — and whose `+` fans Dig / Go in / Bury a truffle. A buried truffle shows as a mound in the yard (`components/BuriedMound.tsx`). Retired that day: the ticket pair, the in-flow notice column (shovel pill, weekly-bounty chip), and the painted barn structure (`components/BarnStructure.tsx`, kept on disk pending the go-in motion decision). Going in still runs the *threshold* sequence (`useBarnThreshold`): the full-screen doors close over the Exterior at `MOTION_DURATION.state` → route push behind closed doors → the room's doors open at the *room* tempo (`celebration`); see `docs/barn-entrance-plan.md`.
- **Interior** — the inside of the Barn. The decoratable space where [[Habitat]] lives. Accessed by tapping the barn structure on the Exterior; opens with a door-swing animation (`HabitatDoorTransition`, room tempo), and closes behind you on exit before the Exterior's threshold doors reopen. Other entries (shop purchase hand-off, friend visit, deep link) skip the Exterior stage and only run the room's own opening; `habitat_opened` carries the entry source as `variant`. Houses Rosie + the player's 6 habitat slots. Friends entering via the [[Visit]] screen see your decorated Interior too.
- **Housing design** — a permanent furnishing unlock in the dedicated Barn catalog, separate from pig cosmetics. Six typed decor positions and a required room theme form one revisioned, atomically saved layout; one design occupies at most one position. New Barns start with the Warm Plank shell and no placed decor; four starter designs are owned for the player to place. See spec 24 and ADR 0008 (including the 2026-09-12 amendment).
- **Barn collection** — always-available Snout furnishings plus exact deterministic milestone requirements. Purchasing unlocks a design; placing it is a separate preview/save action.
- **Wallow gifts** — permanent Barn furnishings: six existing designs at lifetime Wallow ranks 1–6, plus exclusive bronze/silver/gold/celestial shelf keepsakes at ranks 1/3/6/10. Existing designs remain purchasable early; keepsakes are earned only. Their inscription displays the owner’s current permanent rank, including ranks above ten. Private, idempotent grant receipts preserve ownership through season rollover and catch up earlier ranks. Both `20260910120000_habitat_prestige_rewards.sql` and `20260910130000_habitat_completion.sql` were deployed with user authorization on 2026-09-10.
- **Barn acquisition journal** — owner-only source receipts distinguish newly owned from already owned and presentation from inspection. Later acknowledges presentation; New remains until inspection or placement. Device-persisted acknowledgments retry without blocking dismissal, and every batch is bound to an account lifecycle. Acquisition analytics are emitted with new ownership in the grant transaction, never inferred from sale availability.
- **Saved rooms** — two named, revisioned arrangement presets. Saving a preset copies the current draft; using it explicitly commits the room friends see. Activation requires a clean draft. Replacing an active preset’s positions clears its active marker without changing the public room. Separate request receipts support retries and conflicts.
- **Satchel** — the capped bag of [[Find]]s on a profile (cap 6, server-tuned via `app_settings.satchel_tuning`, compiled fallback `constants/satchel.ts`). Filled only by the player's own [[Dig]] (0–2 finds per submitted dig, listed on the receipt as "your Satchel got heavier" or "stayed in the mud" when full). Opened from the Barn button's fan; shown as a strip on the [[Visit]] screen. Toss is the only thing a player can do to a find at home; **giving** is the only other thing, ever — there is no selling, and no currency reaches the giver (the "giving, not earning" spine, `docs/barn-visiting-design.md`). Spec: `docs/satchel-spec.md`. _Avoid_: inventory, loot.
- **Find** — one of twelve pocketable countryside objects a [[Dig]] can drop into the [[Satchel]] (river pebble · blue feather · four-leaf clover · snail shell · brass button · tuft of wool · red berries · pinecone · old key · honeycomb chip · glass marble · tin whistle). Three rarities that live in Collect (the catalog's silhouettes lift on first carry) and never in the payout. Art: `assets/images/glyphs/finds/`. _Avoid_: item (that is a cosmetic), Dig Find (that is what a Truffle Patch banks).
- **Wish** — the one live [[Find]] a pig is hoping for. Server-rolled per profile (70/25/5 by rarity), rerolls on fulfilment, on a 48-hour timer, or once per wish by the owner's free "Not this one" — never chosen from a catalog (a request economy takes; a rolled wish is the pig's). Visitors see it as a thought bubble over the host pig; the Friends row marks a friend whose wish is in your bag ("you have it").
- **Delivery** — a visitor handing the host pig the [[Find]] it [[Wish]]es for (`fulfil_pig_wish`). One per (giver, host) per wish. Both pigs get the same flat tickles (3; `apply_tickles`, never the bank), happiness at the visit's rates, the giver a generous tick and a pair visit-streak credit, the find moves to the host's **shelf**, the host gets a while-away line, and the wish rerolls away from the find just given. The giver's count sits beside tickles on the Board ("N delivered") and pays a **keepsake** at 10 / 50 / 100 — drawn from the finds themselves, no currency. Allowed after the visit's tickles are spent and from the nap card, so a sleeping barn is never a dead end.
- **Barn wishlist** — a private collection bookmark. Visiting players inspect only the host’s saved snapshot and public catalog requirements, then bookmark or open the item in their own collection. A visit never exposes the host’s private journal, inventory, wishlist, or presets.
- **Saved room** — the last committed Barn snapshot. Friends read this authorized snapshot, never the owner’s draft or inventory; inspection does not begin a Visit.
- **Habitat** — the player's decorated Interior. Composed of 6 typed slots (back wall, ceiling hanging, floor-left, floor-right, floor centerpiece, accent surface) plus an interior background (wallpaper/floor combo). Slot-based placement: items are typed and route to their matching slot — no free-drag chaos. Internal/technical name is `habitat`; player-facing surfaces refer to "the Barn" (the building itself).
- **Beyond the Hedge** — Rosie's idle-adventure universe, where the ordinary countryside around the Barn becomes a deep, cozy micro-wilderness at pig height. Its core belief is that familiar places contain impossible depth and Rosie may notice something nobody else would.
- **Adventure** — a period when Rosie leaves Home to explore a chosen destination with a chosen trip shape, Tool, Pack, and Intention. The player authors the preparation; Rosie authors what happens. _Avoid_: mission, deployment, quest.
- **Bag** — Rosie's travel object: it carries up to one freely chosen Provision, Tool, and Pack from what the player has acquired, and visibly remembers past Adventures through earned marks. Any slot may be left empty; preparation changes the Adventure but never blocks departure. It is not the player's general-purpose inventory and never auto-fills a prescribed best loadout. _Avoid_: backpack inventory, loadout grid.
- **Tool** — a reusable Bag item that gives Rosie a meaningful verb or way to perceive an encounter. _Avoid_: weapon, stat stick.
- **Pack** — a reusable Bag item that changes what kind of Find Rosie can carry, protect, preserve, or share on the return Home. _Avoid_: inventory expansion.
- **Intention** — the player's plain-language request for what Rosie should pay attention to during an Adventure; it biases her choices without guaranteeing an outcome. _Avoid_: objective, loot filter.
- **Find** — a named object, creature record, clue, story, or phenomenon Rosie brings Home from an Adventure. Generic currency is never the headline Find. _Avoid_: loot, drop.
- **Discovery** — the first meaningful encounter with a distinct Find, place, creature, or phenomenon; it becomes part of Rosie's remembered world rather than merely increasing a count.
- **Near-Discovery** — a specific possibility Rosie encounters but cannot fully reach, understand, or preserve with her current preparation. It explains what kind of capability could change a future Adventure. _Avoid_: failed roll, gear check.
- **Farm stock** — the Home-held supply of Seeds, Compost, harvested ingredients, and Materials used by Rosie's farming loop. It is separate from the [[Bag]], which carries only Adventure preparation.
- **Seed** — a crop-specific item in [[Farm stock]] that is consumed to plant one bed. Adventures and Discoveries are the primary source of new Seed types.
- **Compost** — an optional consumable from [[Farm stock]] that both shortens a crop's growth time and produces a visibly larger harvest. It is never required to farm or used as a planting gate.
- **Crop** — a named plant grown in one bed from one [[Seed]]. Each Crop has its own growth duration, ready appearance, harvest output, and use; short and long Crops coexist so the player can plan and build [[Farm stock]] over repeated harvests. Once ready, a Crop waits safely and never spoils or loses yield.
- **Harvest** — the player action that converts one ready [[Crop]] into its crop-specific output in [[Farm stock]] and returns the bed to empty. Compost increases the amount without changing the output's identity. Base yield is guaranteed; performing the optional [[Harvest Rhythm]] well adds a small deterministic bonus.
- **Harvest Rhythm** — an optional, short swipe phrase performed over a ready [[Crop]]. Every Crop has its own personal direction, tempo, and momentum pattern built from a small shared gesture vocabulary. Long-growing Crops feel slower and heavier but never use tighter timing as punishment. It adds a small deterministic bonus to the guaranteed [[Harvest]] but never blocks harvesting, removes yield, or creates failure.
- **Material** — a non-headline resource Rosie can bring Home and spend on lasting farm, [[Tool]], or [[Pack]] improvements. A Material supports progression but never replaces a named [[Find]] as the emotional return payoff.
- **Provision** — a harvested or prepared farm output placed in Rosie's [[Bag]] for one Adventure. It is consumed by the trip and changes what Rosie can safely do or how long she can remain away.
- **Field Guide** — the evergreen discovery journal of the game's economy objects (truffles, snouts, wraps, lucky numbers, troughs, the Exchange, the feeding rhythm), living as a second shelf beside the seasonal [[Burrow Book]]. A journal, not a manual: every entry shows as a mysterious silhouette until the player first _meets_ the thing, then opens with a ceremony reveal — one whimsy line of what it is, one honest line of what it does or pays, with real numbers fed from server config so the guide can never lie after a rebalance. Feeling-surfaces (Mood, personal Streak fire, Visit Streaks, happiness) are excluded by design — they explain themselves or stay mysterious (show-don't-tell).
- **Burrow Book** — the seasonal Pokédex-style shelf of a season's unique relics (route `dig-collection`): silhouettes until first catch, found-counts on dupes, set completion pays the season's dig-exclusive cosmetic. Seasonal where the [[Field Guide]] is evergreen; the two share one discovery home.
- **The Great Hunger** — Season 1's cooperative world-boss arc. The opening cinematic must anchor on the game's real art (Rosie's real sprite at `assets/images/sprites/rosie/idle_1.png` / `~/Desktop/ttp-refs/soccer-regen/idle_1.png`, and the selected Truffle King/Hunger reference), not an invented sticker/gouache/felt style. Its seven-shot story ends down: joy → theft → grey → empty world → the Hunger begins. Rosie does not win or look victorious in the intro; players earn the win through the co-op dig (every Sounder's finds starve him — no pig fights another pig).
- **Wallow** — the evergreen prestige lap after a pig earns one full pass-length of season XP. Wallowing keeps claimed rewards and overflow XP, raises permanent `profiles.wallow_count`, and starts a fresh visible Prestige Path (375 snouts, four Golden Truffles, one Mystery Hat Box per lap, plus five Motes from permanent rank 3). Permanent power currently runs through W6: the configured interval reduction is +25 percentage points at W1 and W2, then +5 points per rank to a 70% shorter base interval; the shared three-Barn visit window also falls from 8 hours at W0 to 3 hours at W5+. `user_season_progress.wallow_count` is the season-local lap; `profiles.wallow_count` is permanent rank. Exact server tuning lives in `app_settings.wallow_tuning`.
- **Pig roster** — the pigs a player can choose for Home. Rosie is every player's permanent default. An active Slop Club member makes one **long-term companion choice** from Copper, Pepper, Bandit, Pickles, or Biscuit; that companion cannot be replaced for now, but the player can freely choose whether Rosie or their companion appears on Home from **The Pen** in the Shop. A lapsed member keeps the current companion but sees Rosie until membership resumes. Each identity has a complete baked main + Lounge animation pack authored from Rosie's poses. `utils/pigRoster.ts` + `hooks/usePigRoster.ts` own the client seam; the `pig_roster`, `recruit_pig`, and `activate_pig` RPCs own authorization and invariants.
- **Rosie's Loadout** — TTP's physical illustration-first card game. Rosie is its lead character and mascot; Rosie, Copper, Pepper, Bandit, Pickles, and Biscuit are the six playable **Legends**.
- **Legend** — Rosie's Loadout's top-level pig card class. Choose one before deck building and keep it face up outside the deck in the Legend zone. A Legend starts at 12 Cheer, defines two favored styles, has one unique ability, and gains levels/actions through [[Training]]. Legends are guaranteed play pieces rather than random deck pulls.
- **Training** — a Rosie's Loadout deck card's alternative use: tuck it beneath the Legend instead of playing it normally, permanently adding one level, one style icon, and an exposed action strip.
- **Critter** — a friendly small-creature card in Rosie's Loadout, such as a firefly, spider, frog, or mouse. Use _Critter_, not _Companion_: Companion already means the player's long-term non-Rosie pig-roster choice.
- **Enemy** — a Rosie's Loadout obstacle or antagonist placed into an opponent's Trouble row. Enemies may be mischievous, hungry, or lonely rather than evil.

## Seams

- **Receiver-side effects layer** — `hooks/useActiveEffects.ts` + `utils/activeEffects.ts`. Single owner of the read path (fetch, focus refresh, realtime subscription on blessings + curses) and the cleanse mutation (optimistic + RPC). Consumers: `components/ActiveEffects.tsx` (Inbox panel — the one place the blessing/curse detail now reads, since the Barn chips strip, the Hoofprints bottom sheet and the Updates tray that housed them were deleted 2026-09-12), `components/Barn.tsx` (derives `{blessed, cursed, sunBeam, phantomItch}` predicates for the BarnOverlay theming + lucky-pig sunBeam boost + phantom-itch miss gate). `components/CleanseModal.tsx` is pure UI behind `onConfirm`.
- **RPC layer** — `utils/rpc.ts` exports a single generic `rpc<T>(name, params?)` that absorbs the supabase-rpc cast + null/error handling for every call site in the app (~67 sites). Errors flow through `log.error()` to Sentry; callers receive `T | null` and pattern-match on the result. Named typed wrappers per RPC grow organically alongside each feature's deepening (see `utils/activeEffects.ts`, `utils/friendships.ts`).
- **Friendships layer** — `utils/friendships.ts` owns the friendship contract: the `FriendshipStatus` type, `FRIEND_CAP_LIMIT`, the `friendActionMessage(reason, cap, name)` error-to-copy helper, and typed wrappers around the six friendship RPCs (`getFriendIds`, `sendFriendRequest`, `acceptFriendRequest`, `cancelFriendRequest`, `getSuggestedUsers`, `searchUsers`). Render surfaces (Friends, UserSheet, Leaderboard, Inbox) consume it. Moderation (block / report) stays outside — different domain.
- **Barn orchestrator** — `components/Barn.tsx` is the home-screen orchestrator. Five hooks own the data + logic subsystems it used to inline: `useHomeStats` (stats state + `home_stats` RPC + refresh), `useStipend` (Slop Club monthly claim), `usePassEvents` ("X just trotted past you" dedup + toast emission), `useLuckyPig` (trigger / window / double rolls + AsyncStorage persistence + one combined Lucky Pig/title reward modal), `useActiveEffects` (the ritual-effect predicates that gate the lucky-pig sunBeam boost + phantom-itch miss + drive BarnOverlay theming). Cross-hook coupling is explicit via callback props at the top of Barn — `onClaimed: homeStats.refresh`, `showToast: barnShowToast`. Pure roll math lives in `utils/luckyPig.ts` and is unit-tested. Toast queue, heart floats, alignment watcher, the inline six-seven animation, tickle handlers, and pig animations stay in Barn. Release notes are manual-only in Me.
- **IAP adapter pair** — `utils/iap.ts` defines an `IAP` interface and two plain-object adapters: `realIAP` (wraps RevenueCat) and `noopIAP` (cancelled / empty for every method). Module-level `iap = IAP_ENABLED ? realIAP : noopIAP` picks one at load time; public re-exports (`isPro`, `presentPaywall`, etc.) delegate. Kill-switch decision concentrates at the seam instead of branching inside each function body. A future `mockIAP` for tests slots in as a third adapter with no call-site changes.
- **Race module** — `utils/race.ts` (split from `utils/dig.ts`, which keeps only the dig/feeding reads + milestone mapper): race server-contract types, the defensive standings parsers, fetches, cycle math, and the pinned-row selectors. Consumers: `useRace`, RaceSection, race-standings, SounderHomeCard (mixed import, split by side).
- **Duration module** — `utils/duration.ts` (absorbed `utils/time.ts`): three deliberately distinct formatters (`formatDurationCompact` rounds + collapses exact hours, `formatCountdownHM` floors, `formatClockMS` is a mm:ss clock with no hour rollover) + `remainingMs(iso)`. Callers keep their exact historical strings — do not merge the variants.
- **Leaderboard layer** — `hooks/useLeaderboard.ts` owns scope fetches, cursor pagination (hasMore/dedupe), and the `mark_all_pass_events_seen` side-effect; `components/Leaderboard.tsx` is rendering + UI state. **Pot-stake machine** — `hooks/usePotStake.ts` owns the sel/max/validity state machine both bury sheets share (chip styling + refusal copy stay per-sheet; pure math stays in `utils/burySnouts.ts`).
